# 第二阶段产品范围

`product-v1.md` 是第一版历史：连接、手工发布、SSE 和设备授权。本文描述现行信息架构和领域范围。实现细节与验收缺口以 `docs/release-readiness.md` 为准；不要把「目标模型」写成已经完成的会计或尚未开工的适配。

## 核心原则

统一入口、统一展示、统一身份和任务状态；不同业务保留各自的数据模型。

不把所有内容继续塞进 `posts`，也不把信息流、灵感、知识和 AI 结果混成一张大表。

## 信息架构

默认落地页是 **总览**（`#sources`）。总览点开后二级是 **总览 | 信息流 | 股票 | 全球行情**。

- 总览：左侧紧凑行情与近期日程，右侧最新内容；完整市场原生数据仍在总览下方，不另开一级。
- 信息流：统一投影社媒、字幕、手工发布和官方索引；`#feed` 从总览二级进入，不再叫「社媒」。
- 股票 / 全球行情：原来市场页的两个看板。宽屏仍用底部五项导航，不切成左侧栏。
- 灵感：从工具里提出，作为一级入口（`#inspire`）。

桌面与手机同一组五项底栏：**总览、灵感、问答、资产、工具**。信源、任务、自动化和设备连接放在设置入口层。`#account` 映射到设置。旧地址 `#trade` 兼容跳到 `#market`。

| 一级入口 | 二级结构 | 定位 |
|---|---|---|
| 总览 | 总览、信息流、股票、全球行情 | 内容时间线与看盘；信息流含官方/社媒/手工；股票/全球行情即报价 |
| 灵感 | 记下、列表 | 留下未完成的思考；默认只保存原文 |
| 问答 | AI 记录、新问答 | 研究记录与可继续的问答会话 |
| 资产 | 持仓、个人资产分析 | 我的持仓账本与个人财务大屏 |
| 工具 | 知识库、日报、连接 | 长期沉淀与来源维护；任务在设置里 |
| 日报 | 今日、历史 | 跨模块汇总；入口仍在工具页 |

### 信息

- 全局筛选是 `全部 / 重点 / 社媒 / 官方`。官方条目是 Source Snapshot 投影，不写入 Feed 表。
- `关注` 只属于 X 信源内部的「为你推荐 / 正在关注」，不再占据全局第二筛选项。
- `B站 / X / 手工` 进入信息流筛选，不与主筛选同层。
- 默认按收录顺序（`capturedAt`）排列，已读下沉；「按发布时间」是显式切换，不是默认。
- 星标是本机「重点」；存入灵感仍是书签，两者分开。
- 不提供「推荐/热门」，直到有真实排序与行为数据。
- 关注对象是 `SourceAccount -> Subscription -> SyncJob -> Capture -> ContentItem`。
- B站新视频先进入信息流；字幕和总结异步更新卡片。

### 市场

顶层随总览二级进入：`股票 | 全球行情`。这是看盘，不是下单。不单独设市场一级。

- 股票：`总览 / A股 / 美股 / 亚洲`。总览是指数和宽度；北京时间工作日 17:00 前显示 A 股观察，17:00 后及周末显示美股观察。A 股、美股、亚洲分览是已设计的观察池分组。亚洲 KR/JP/TW 观察池仍单独成页，不被 A 股看板覆盖。
- A 股当前种子是国产半导体产业地图（nano-ai 2026-09-17 研究底库，非推荐池，大量公司待核验）；同一公司可以出现在多个分组。A 股 / 港股通 / B 股现价优先走雪球批量行情；同花顺快照作缺票回退，未覆盖标的仍可能走 Yahoo。美股与亚洲观察池看板仍走 Yahoo。
- 全球行情：指数、外汇、利率、贵金属、能源、期货、加密；复用同一行情列表。
- 总览另外展示 Market-native Data：Polymarket / Kalshi 的独立事件报价、Hyperliquid BTC/ETH 永续状态、DefiLlama 稳定币供给。这里只展示 Price、Volume、Liquidity、OI、Funding、Supply、Time，不替代传统行情，也不输出方向判断。

### 资产

顶层：`持仓 | 个人资产分析`。流水进入持仓详情。个人资产分析读取本地「收支草记」工作簿，不替代持仓流水核算。

- 持仓：分 `A股 / 港股通 / B股沪 / B股深`；总览给出 A股资产、B股资产（实时汇率折人民币）和账户现金。
- 手工持仓以 `holding_lots` 为批次账本，便于增删；价格走行情 Adapter，不把券商字段暴露给页面。
- 当前仍是手工批次账本（`HoldingLot`）：加减仓改批次，不宣称完整交易流水会计。目标模型仍是 `Transaction` 可重建持仓，尚未当作已交付。
- P0 手工录入持仓 + 自动刷新价格；券商同步后置。
- 当前没有下单入口，因此不设「交易」一级菜单。

### 灵感、知识与问答

- 灵感打开即可写；默认只保存，不自动调用 AI。
- HarmonyOS 支持从系统分享面板接收文字和链接，在原生分享详情页预填原文与来源，用户确认后先保存到本机；也提供可直接输入、查看和删除的本地灵感页。未配对或离线不阻塞记录，连接恢复后单向幂等上传。手机删除只清理手机副本，不传播到 AI Center；服务端记录不反向灌入本地列表。不做无界面静默落库。
- 灵感区分业务来源（`sourceType/sourceId`）与采集入口（`captureChannel`），外部分享可保留 `sourceUrl/sourceTitle/sourceApp`，来源字段不拼进原文。
- 原文永久保留；AI Run 单独记录模型和提示。
- 知识库不是归档灵感列表，而是可长期复用内容的规范层。分类使用多维 Taxonomy（domain / topic / industry / market / asset-class / lens / platform / project），页面可以展示成路径，数据库不做成单一目录树。`knowledge_type = thesis` 只是文档类型，不是新的 Thesis 领域。给 Agent 重复使用的投资框架另以仓库 `knowledge/**/*.md` 存放，经同一套 `knowledge.search` / `knowledge.get` 读取；人看的解释稿不写入该树。
- 问答分两层：第一层是 `AiSession` 记录列表（问答、灵感加工等 AI 处理都进入这里），可回溯；第二层是具体会话，可基于当前上下文继续追问，或从第一层点 + 开新问答。提问入队后由 Worker 继续执行，离开问答页不取消任务。列表、会话和底栏要能看见排队/进行中，点进会话继续轮询进度。多问走队列（Worker 一次一条），不是多 Agent 并行。
- 问答统一经 Context Service 读取**当前**数据并带来源；继续旧会话时保留该会话历史，工具读取的是此刻的知识库、信息流和持仓，而不是提问当时的冻结快照（`AiRunContextRef` 仍用于单次复盘）。
- 日报先定数据结构，P2 再生成。

## 本轮明确不做

- 不把旧仓库代码迁入本仓库。
- 不在前端包里直接调用 B站/X Skill 或雪球/同花顺/Yahoo。
- 不把旧服务端口暴露给手机。
- 不实现推荐算法、多人采集节点或应用商店发布。
- 不提前增加 InvestmentPolicy、Strategy、Decision、Thesis、Review 等领域；投资方法仍作为可修订知识自然生长。
