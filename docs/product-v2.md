# 第二阶段产品范围

`product-v1.md` 仍是第一版历史：连接、手工发布、SSE 和设备授权。第二阶段从 UI 原型转到领域底座，以及两条真实链路（信息流抓取、交易）。

## 核心原则

统一入口、统一展示、统一身份和任务状态；不同业务保留各自的数据模型。

不把所有内容继续塞进 `posts`，也不把信息流、灵感、知识和 AI 结果混成一张大表。

## 信息架构

手机底栏与桌面侧栏使用同一组一级入口：

| 一级入口 | 二级结构 | 定位 |
|---|---|---|
| 信息 | 全部、关注 | 外部信息和手工发布的统一入口 |
| 交易 | 股票、全球资产、持仓 | 行情、自选、账户资产 |
| 工具 | 灵感、知识库 | 用户主动输入和长期沉淀 |
| 问答 | 搜知识库、追问来源 | 知识消费入口 |
| 日报 | 今日、历史 | 跨模块汇总 |

账户、设备、连接器和数据源放到右上角设置，不再占底栏。`#account` 继续映射到设置页。

### 信息

- `全部` 在第一位：人工发布、B站、X 等标准化内容。
- `关注` 在第二位：只显示用户明确关注的账号/频道。
- `B站 / X / 手工` 是平台筛选，不与「全部/关注」同层。
- 不提供「推荐/热门」，直到有真实排序与行为数据。
- 关注对象是 `SourceAccount -> Subscription -> SyncJob -> Capture -> ContentItem`。
- B站新视频先进入信息流；字幕和总结异步更新卡片。

### 交易

顶层：`股票 | 全球资产 | 持仓`。流水进入持仓详情。

- 股票：`总览 / 美股 / 亚洲`。总览是指数和宽度；美股、亚洲是已设计的观察池分组。
- A 股同花顺行情尚未接入。
- 全球资产：指数、外汇、利率、贵金属、能源、期货、加密；复用同一行情列表。
- 持仓：同样分 `A股 / 美股`；总览分开今日盈亏、持仓盈亏、总收益。
- 加减仓必须生成流水，不直接改最终收益。
- P0 手工录入持仓 + 自动刷新价格；券商同步后置。

### 灵感、知识与问答

- 灵感打开即可写；默认只保存，不自动调用 AI。
- 原文永久保留；AI Run 单独记录模型和提示。
- 知识库不是归档灵感列表，而是可长期复用内容的规范层。
- 问答默认只检索知识库并带来源；「包含最近信息流」是显式开关。
- 日报先定数据结构，P2 再生成。

## 本轮明确不做

- 不把旧仓库代码迁入本仓库。
- 不在前端包里直接调用 B站/X Skill 或同花顺/Yahoo。
- 不把旧服务端口暴露给手机。
- 不实现推荐算法、多人采集节点或应用商店发布。
