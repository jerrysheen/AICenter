# 第二阶段产品范围

`product-v1.md` 是第一版历史：连接、手工发布、SSE 和设备授权。本文描述现行信息架构和领域范围。实现细节与验收缺口以 `docs/release-readiness.md` 为准；不要把「目标模型」写成已经完成的会计或尚未开工的适配。

## 核心原则

统一入口、统一展示、统一身份和任务状态；不同业务保留各自的数据模型。

不把所有内容继续塞进 `posts`，也不把信息流、灵感、知识和 AI 结果混成一张大表。

## 信息架构

默认落地页是 **总览**（`#sources`）。总览点开后二级是 **总览 | 信息流 | 股票 | 全球行情**。

- 总览：左侧紧凑行情与近期日程，右侧最新内容；事件市场留在总览下方。Hyperliquid 与稳定币并入全球行情。
- 信息流：统一投影社媒、字幕、手工发布和官方索引；`#feed` 从总览二级进入，不再叫「社媒」。官方条目按日排成可点开的时间线，不复用社媒卡片。
- 股票 / 全球行情：原来市场页的两个看板。宽屏仍用底部五项导航，不切成左侧栏。
- 灵感：从工具里提出，作为一级入口（`#inspire`）。

桌面与手机同一组五项底栏：**总览、灵感、问答、资产、工具**。信源、任务、自动化和设备连接放在设置入口层。`#account` 映射到设置。旧地址 `#trade` 兼容跳到 `#market`。

| 一级入口 | 二级结构 | 定位 |
|---|---|---|
| 总览 | 总览、信息流、股票、全球行情 | 内容时间线与看盘；信息流含官方/社媒/手工；股票/全球行情即报价 |
| 灵感 | 随记、任务 | 留下未完成的思考；任务是给本机 Cursor 的产品不足投递箱，完成后状态写回任务卡 |
| 问答 | AI 记录、新问答 | 研究记录与可继续的问答会话 |
| 资产 | 持仓、个人资产分析 | 我的持仓账本与个人财务大屏 |
| 工具 | 知识库、日报、连接 | 长期沉淀与来源维护；任务在设置里 |
| 日报 | 今日、历史 | 跨模块汇总；入口仍在工具页 |

### 信息

- 全局筛选是 `全部 / 重点 / 最近 / 社媒 / 官方`，同一行可滑入 `X / 雪球 / B站` 信源快捷入口。官方条目是 Source Snapshot 投影，不写入 Feed 表；官方筛选按发布日排成时间线，点进去看详情，后续可带进问答。
- `关注` 只属于 X 信源内部的「为你推荐 / 正在关注」，不再占据全局第二筛选项。
- 右侧始终是同一个折叠按钮：范围页打开筛选（排序、日期、平台含手工）；切到 `X / 雪球 / B站` 时仍是这个按钮，打开该信源任务，不再先选平台再进子菜单。
- 默认按收录顺序（`capturedAt`）排列，已读下沉；「按发布时间」是显式切换，不是默认。
- 星标是本机「重点」收藏：单独保存条目副本，其他栏目删除不影响；重点里再删才去掉。已读半透明只在重点。存入灵感仍是书签；已译条目保存当时显示的中文，不把英文原文写进灵感正文，也不改信息流原文。
- 「最近」是本机浏览记录：打开一条就另存副本，按浏览时间排列，方便找回看过后从其他栏目消失的内容；最近里再删才去掉这份记录。
- 不提供「推荐/热门」，直到有真实排序与行为数据。
- 关注对象是 `SourceAccount -> Subscription -> SyncJob -> Capture -> ContentItem`。
- B站新视频先进入信息流；字幕和总结异步更新卡片。

### 市场

顶层随总览二级进入：`股票 | 全球行情`。这是看盘，不是下单。不单独设市场一级。

- 股票：`总览 / A股 / 美股 / 亚洲`。总览是指数和宽度；北京时间工作日 17:00 前显示 A 股与港股观察（上证50 / 创业板50 / 科创50 / 恒生 / 港科），17:00 后及周末显示美股观察。A 股、美股、亚洲分览是已设计的观察池分组。亚洲 KR/JP/TW 观察池仍单独成页，不被 A 股看板覆盖。美股看板只挂美股行情代码，亚洲看板只挂 KR/JP/TW 本地代码，两边接入的是不同上市市场，不混用。
- A 股当前种子是国产半导体产业地图（nano-ai 2026-09-17 研究底库，非推荐池，大量公司待核验）；同一公司可以出现在多个分组。A 股 / 港股通 / B 股现价优先走雪球批量行情；同花顺快照作缺票回退，未覆盖标的仍可能走 Yahoo。美股与亚洲观察池看板仍走 Yahoo。
- 全球行情：指数、外汇、利率、国债、贵金属、能源、期货、加密；复用同一行情列表。利率追美债 2/5/10/30，国债追中金所 2/5/10/30 主连，商品含碳酸锂、白银、豆粕等。加密筛选同时展示 Hyperliquid BTC/ETH 永续状态和 DefiLlama 稳定币供给，不另开一级。
- 总览下方只留事件市场：Polymarket / Kalshi 按关注主题列出，每个事件显示该场所的 Yes / 对立报价（百分比），必要时附上次成交。不把两个场所合成“真实概率”，也不输出方向判断。

### 资产

顶层：`持仓 | 个人资产分析`。流水进入持仓详情。个人资产分析以 SQLite 账本为真源：上面是统计，下面按来源分组记录。类型是银行卡 / 投资等配置项，账户是银行卡1 + 备注；收支草记只作导入。持仓股票市值与券商现金加总进投资类，不替代持仓流水核算。分红榜本版不展示。

- 持仓：分 `A股 / 港股通 / B股沪 / B股深`；总览给出 A股资产、B股资产（实时汇率折人民币）和账户现金。
- 手工持仓以 `holding_lots` 为批次账本，便于增删；价格走行情 Adapter，不把券商字段暴露给页面。
- 当前仍是手工批次账本（`HoldingLot`）：加减仓改批次，不宣称完整交易流水会计。目标模型仍是 `Transaction` 可重建持仓，尚未当作已交付。
- P0 手工录入持仓 + 自动刷新价格；券商同步后置。
- 当前没有下单入口，因此不设「交易」一级菜单。

### 灵感、知识与问答

- 阅读、灵感详情、问答 Session 和任务详情共用同一套 Detail Shell：顶栏只负责导航；对象标题 / 状态 / 来源 / 时间在页头；主内容用白底和留白；分析、进度、AI 结果才用浅灰 Surface；对象操作放在内容下方。返回只出现在顶栏，不进入正文操作区。二级问答页顶栏直接显示「新提问」或会话标题。
- 灵感打开即可写；默认只保存，不自动调用 AI。任务在灵感下的独立窗口（`#inspire/tasks`），不混进随记列表。投递当下先落盘 `goal` / `progress`；一级任务列表只显示主题和两句摘要，点进详情再看状态、目标、进展。执行记录与问答共用 `AgentRunProgressStep` 时间线（历史步折叠、当前步展开）。`open` 是排队/等待，只有 `claimed` 才显示运行中；不能用假的「正在思考」掩盖尚未执行。派发目前仍走本机 Cursor CLI；下一步才是同一 Harness、Host 写盘剖面。详情里可回看全过程、下新指令开新 session，或对完成/失败任务点「重新做」创建带 parent trace 的新任务；原任务不覆盖。上一任务、上一过程与上一结果分段展示，主题取最新继续指令。刷新后按路由回到当前问答或任务。Worker 领取后补写提示词并拉起本机 Cursor CLI 做这一条；默认同时最多 3 个 CLI，问答仍一次一条。每一步写入 JSON，做完进程退出，`resultSummary` 写回任务卡。静态页立刻生效；改了 `apps/web/src`、Worker 或 `packages` 才由启动器弹 Web/Worker，隧道保持。远端可在设置里请求同一次重启。当前对话只是收件箱。
- HarmonyOS 支持从系统分享面板接收文字和链接，在原生分享详情页预填原文与来源，用户确认后先保存到本机；也提供可直接输入、查看和删除的本地灵感页。未配对或离线不阻塞记录，连接恢复后单向幂等上传。手机删除只清理手机副本，不传播到 AI Center；服务端记录不反向灌入本地列表。不做无界面静默落库。
- 灵感区分业务来源（`sourceType/sourceId`）与采集入口（`captureChannel`），外部分享可保留 `sourceUrl/sourceTitle/sourceApp`，来源字段不拼进原文。
- 原文永久保留；AI Run 单独记录模型和提示。
- 知识库不是归档灵感列表，而是可长期复用内容的规范层。分类使用多维 Taxonomy（domain / topic / industry / market / asset-class / lens / platform / project），页面可以展示成路径，数据库不做成单一目录树。`knowledge_type = thesis` 只是文档类型，不是新的 Thesis 领域。给 Agent 重复使用的投资框架另以仓库 `knowledge/**/*.md` 存放，经同一套 `knowledge.search` / `knowledge.get` 读取；人看的解释稿不写入该树。
- 问答分两层：第一层是 `AiSession` 记录列表（问答、灵感加工等 AI 处理都进入这里），可回溯；第二层是具体会话，可基于当前上下文继续追问，或从第一层点 + 开新问答。已完成的一轮可在卡片上导出 PNG：先出预览小窗再保存（克隆当前渲染，问题用普通正文，不另做 Markdown 出图）。同一会话的每次追问在后台仍是独立 Job / AiRun，前端必须渲染成一个连续 conversation，而不是多张互不相关的任务卡。提问入队后由 Worker 继续执行，离开问答页不取消任务。列表、会话和底栏要能看见排队/进行中，点进会话继续轮询进度；运行中始终展开当前步骤，此前步骤折叠为可点击的历史。阅读回答并向下滚动时，输入栏收成单行，释放回答视区；点击、聚焦或输入时恢复完整工具栏和多行高度。多问走队列（Worker 一次一条），不是多 Agent 并行。问答可开「专业研究」：走更高模型档位接口，研究方法关键词与额外工具口已留，当前清单为空。
- 问答统一经 Context Service 读取**当前**数据并带来源；继续旧会话时保留该会话历史，工具读取的是此刻的知识库、信息流和持仓，而不是提问当时的冻结快照（`AiRunContextRef` 仍用于单次复盘）。
- 信息流 / 灵感上的引用是一组材料，不是问答私有状态。点选后可导出 Markdown（日期、来源、译文）、放进任务投递框，或带去问答。不另开选择向导，也不在这一步接云端 GPT 隧道。
- 日报先定数据结构，P2 再生成。

## 本轮明确不做

- 不把旧仓库代码迁入本仓库。
- 不在前端包里直接调用 B站/X Skill 或雪球/同花顺/Yahoo。
- 不把旧服务端口暴露给手机。
- 不实现推荐算法、多人采集节点或应用商店发布。
- 不提前增加 InvestmentPolicy、Strategy、Decision、Thesis、Review 等领域；投资方法仍作为可修订知识自然生长。
