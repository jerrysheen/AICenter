# 日报分析 V2

2026-10-05 用户授权改为信息摘选，生产 Worker 新稿使用 `information-digest-v1.md`。
本文的主题正文流程保留旧阶段、旧稿与显式兼容回放；不再驱动新稿的主要产物。

本轮由用户授权升级现有日报。采集频道、选文规则、Tag 与翻译保持各自职责。
DailyReport 继续是确定性材料快照；V2 在同一个 Worker、Repository 和 Harness 上按来源分批阅读，
社交 → 新闻独立阅读及对照 → 已启用的问题 → 编辑成稿。旧快照和旧 Brief 兼容读取。

窗口沿用 Instance 配置，左闭右开；冻结时间、生成时间、原文时间和后到材料分开记录。
Feed 与媒体索引各自按来源 keyset 分页，媒体以保存正文为准，不以提要、译文或 Tag 为门槛。
单源材料上限与总字节上限均有覆盖统计；预算耗尽不宣称覆盖全日。
正文按段落分批，不把截断摘要当全文；编辑仅引用前轮实际读到的原段落。
材料携带原文总段数，contentLevel只表示保存版本的完整度，不表示本批读完全文。
分批片段不能描述成全文仅有这些段落，窗口事件多寡不能由未覆盖的样本推断。

追踪问题由 Report Repository 保存，通过日报页编辑并明确启用，初始为空。
历史判断只作假设，关联其证据与日期；问题改名后不继承旧判断，无新证据与读取失败分别表达。
没有配置时显示尚未配置，不自动从聊天、持仓或模型建议创建问题。

HTTP 只入队：普通重新生成重建所选日期材料；固定材料重写使用已经冻结的版本，复用阅读结果。
V2 保存阶段输入、哈希、结果和失败状态；失败重试只执行缺失阶段。
同窗口、输入与流程版本通过运行租约防止重复；有效旧结果在新稿完成前继续可读。
失败页提供继续本轮分析，不重新汇集材料；自动补跑也保留原材料版本与重写标识。
V2 引用按生成版本读取归档；首次升级时归档原旧稿，已有引用仍可查。
旧版之间的重生成保持版本不匹配即 missing 的兼容行为。

本轮采用封闭材料模式：无 SQL、文件、任意 URL 或联网工具。具体未知保留为未知。
外部补查为后续可选能力，不能假装已经核验。行情标明实际数据时间、获取时间、陈旧和后于窗口。

验收先用固定样本，再对已结束窗口只读回放；回放使用临时数据库，不覆盖原日报。

真实回放发现大批次与过长中间输出会超过阶段截止，默认改为10KB分片阅读。
社交最多14批、新闻最多64批、总调用100次、阅读/追踪阶段180秒、编辑成稿360秒、每轮生成总计60分钟。
这些均为内部固定预算，不从HTTP接收任意额度；未读量随成稿保存，达到截止保留检查点。
阅读先为追踪与编辑预留时间，社交最多占可阅读时间的35%，确保新闻有独立时间额度。
达到阅读预算可依据已读材料生成明确标注未读量的部分覆盖稿；单阶段失败仍保留旧稿并续跑。
编辑仅带14KB关键原段落与8KB分析索引，不重新塞入全部全文。
编辑输入压缩来源覆盖与证据的冗余元数据，完整来源和覆盖仍保存于版本快照。
模型调用期间每分钟续租运行，延长编辑截止不会失去原有四分钟租约。
Harness SDK请求截止随阶段配置隔离；重试保留同流程版本的已完成阅读，仅重做失败成稿。
