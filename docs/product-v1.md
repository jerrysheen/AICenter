# 第一版产品范围

## 产品目标

在不接入任何旧平台能力的前提下，验证本地电脑与鸿蒙手机之间的信息闭环：

```text
建立连接 -> 查看信息 -> 发布信息 -> 另一端实时出现 -> 重启后仍然存在
```

## 第一版页面

### 连接状态

- 展示服务器名称、版本、在线状态和最近同步时间。
- 桌面端显示手机连接二维码。
- 手机第一次使用二维码中的短期配对码换取长期设备授权。
- 已授权手机以后直接连接，不要求每次扫码。

### 信息流

- 卡片展示标题、摘要、正文、标签、来源链接和发布时间。
- 支持桌面和手机宽度。
- 新信息到达时实时插入列表，不需要手动刷新。

### 快速发布

- 支持标题、正文、来源链接和标签。
- 网页和手机均可发布。
- 发布成功后，两端实时看到同一条内容。
- 第一版附件只预留数据结构；图片上传可在文字闭环通过后补充。

### 信息详情

- 查看完整正文、来源和时间。
- 预留收藏、总结、关联股票和交给 AI 的入口，不实现具体业务。

## 明确不做

- 不迁移 `F:\AI` 和 `F:\Fintech\AI-Hub` 代码。
- 不接入 B站、YouTube、X、小红书、抖音或行情源。
- 不实现知识库、Codex、复杂任务队列。
- 不开放公网访问。
- 不做应用市场发布。
- 不为网页和鸿蒙分别开发两套业务 UI。

## 验收标准

1. 同一局域网内，鸿蒙手机可以通过二维码发现并连接本机服务。
2. 首次配对完成后，关闭并重新打开应用不需要重新扫码。
3. 桌面发布一条信息后，手机在正常网络下 1 秒左右显示。
4. 手机发布一条信息后，桌面端实时显示。
5. 服务重启后，历史信息和设备授权仍然存在。
6. 实时连接短暂中断后自动恢复，不要求人工重连。
7. 用户可以在桌面端撤销某个手机的授权。

## 第一条测试信息

第一条内容使用本地手工数据，不依赖外部平台：

```text
标题：AI Center 已连接
正文：这条信息由本机发布，并已同步到鸿蒙手机。
标签：系统、首发测试
```

## 当前可验证行为

桌面管理端展示最近 24 小时的最小行为指标：

- 已连接且未撤销的设备数。
- 应用打开次数。
- 快速发布数量。
- 信息详情查看次数。

这些指标只用于判断第一版路径是否自然，不采集输入内容之外的浏览数据，也不发送到外部服务。
