# 首屏和列表用骨架

## 原因

已记住登录时，外壳会先出来，总览模块、行情条和信息流还是空的，或者只有一行「正在读取」。数据到达后高度突然变长。直接打开 `#feed` 时，第一帧仍是总览，再切到信息流。

## 决定

`list-skeleton.js` 画出固定高度的列表行和行情条。总览的小时报、最新消息、日报、官方，以及信息流、灵感、任务、知识库、问答记录，在 HTML 里就放好同样的骨架。脚本再次绘制时，行数不变就留着这一份，不先清空。

报价还没到时，总览行情条保持骨架，不先写「--」。作者列表和作者页在请求回来前也用同样的行。失败和真正的空列表仍写原来的说明。

地址已经是 `#feed` 时，打开页面就标上 `feed-boot`，第一帧是信息流骨架，标题是「信息」。进入页面后去掉这个标记。减少动效时骨架不闪动。

不新增 migration。当前 schema 仍是 95。下一号是 96。空号仍是 63、79、80、82。不要重建数据库。需要重启 Web，浏览器再加载一次。Worker 不用为这项重启。
