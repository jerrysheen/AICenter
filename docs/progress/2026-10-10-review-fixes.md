# 2026-10-10 审查阻塞项

公网复测性能已经到线。这一步只修审查里会让内联启动、简报和信息流走错路的问题。

- 内联 `ui-boot` 之前先把 HTML 和脚本的换行收成 LF，CSP 哈希按这份 LF 正文计算，并缓存在静态文件条目上。`.gitattributes` 把 `.js`、`.html`、`.css` 固定为 LF。内联指纹或会话没有提前回来时，`app.js` 打 `ai-center.startup-fallback.ui-revision` / `ai-center.startup-fallback.session`。
- 简报页切到后台只暂停定时器。离开 `#report` 才中止在途请求。阅读折叠和往期日期遇到中止后可以再读。
- `#feed` 每个标签声明自己要的数据源。切到「全部」或「重点」时补拉还没读过的手工信息、X 和雪球；从媒体进来再切走时也会补手工信息。已经读过的源直接复用。
- 「存入灵感」如果笔记还没读，先读笔记再决定是打开还是新建，请求期间按钮不可再点。总览启动仍然不读笔记。
- 总览「全部」只含官方和手工信息。手工信息在总览首屏之后用 `requestIdleCallback` 再拉。「社媒」要点进去才拉 X 和雪球；加载中是加载态，失败是重试，接口确实为空才显示没有内容。总览首屏之前仍然没有 `/feed/x` 和 `/feed/xueqiu`。

新闻筛选、JEV、翻译、小时报/日报和接口契约没有改。没有新依赖，也没有构建步骤。
