# 总览混排与交易拆分

## 目标

把 `#sources` 从连接器目录改成「一眼看到最高优先级内容」的总览；完整信息流仍去信息子页。同时取消「交易」一级菜单，拆成市场（看盘）和资产（账本）。

## 决定

- 总览二级改为 **总览 | 社媒 | 股票 | 全球资产**。社媒即原 `#feed`。股票/全球资产即原市场页。侧栏不再有市场一级。
- `#trade` 兼容跳到 `#market`。领域 Service 仍叫 Trading，页面名称不再叫交易。
- 总览混排真实信息流/行情（有会话时）和 mock 新闻；点卡片进入对应子页或打开原信息详情。

## 改动

- `docs/product-v2.md` 信息架构表。
- Web 导航、总览流、`#market` / `#assets` 两个页面。

## 验证

浏览器走总览混排、信息子页、市场股票/全球资产、资产持仓/个人分析。`npm run check`。
