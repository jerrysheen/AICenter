# 2026-10-12 GPU 租金来源

## 目标

在现有算力价格快照里增加 CCIR、GPU Economy 和 Bargo。字段仍是来源、型号、档位、美元/时、样本数和报价日。

## 决定

三处都沿用同型号中位 40% 和按型号下限。空单元格、无库存占位价和低于下限的价格不保存，跳过原因写入 Worker 日志。报价日优先用页面写明的日期，没有则用抓取日。不新增 migration。不接入 Ornn 或 Silicon Data。

CCIR 用 `https://ccir.io/rates` 的静态阶梯表。默认每天 20:30，21:30 再抓一次。GPU Economy 用各卡页面上的多供应商中位，默认每 120 分钟，页面链到该卡。Bargo 用按需、竞价和预留均价，默认每天 09:00。
