# 观察池领涨领跌显示名字

## 目标

股票总览「观察池宽度」的领涨、领跌显示股票名字。自选在雪球失败、改走同花顺时，名字不再退回代码。

## 决定

- 领涨、领跌主文字按名字（不能等于代码）、板块、代码的顺序取。副标是「板块 · 代码」，相同的一段只写一次。行情源的名字用 `textContent` 写入，不拼进 HTML。整行打开个股页。
- 行布局去掉单独的代码列。名字一行，超长省略；副标用三级文字色；涨跌幅不换行。
- 总览首屏快照给领涨、领跌带上板块，最多 40 字，和完整看板同一套字段。
- A 股看板里，名字如果就是代码，先用 `config/markets.json` 的名字。目录里没有的，用本进程里雪球成功时记下的名字。这份对照只留在内存里，不另发请求，也不写入数据库。
- 总览里没有调用方的 `hubMovers`、`hubStreamItems` 删掉。`renderHubExcerpts` 只为它们服务，页面上也没有对应节点，一并删掉。

## 验证

`node --test test/mover-names.test.js` 覆盖：有名字和板块、名字等于代码、两者都没有、名字含 `<b>` 仍是纯文本、首屏领涨领跌带板块、目录能补上自选名字、同花顺兜底仍用雪球曾经返回的名字。

## 遗留

不新增 migration，schema 版本不变。美股目录本来是英文名，页面显示英文。需要同时重启 Web 和 Worker，浏览器再加载一次。进程重启后，雪球还没再次成功之前，目录里没有的自选会暂时显示代码。
