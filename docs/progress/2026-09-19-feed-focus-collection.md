# 重点改成独立收藏，已读不再透出删除

## 目标

信息流「重点」和其他栏目分开：加入时单独保存一份，别的栏目删除不影响；重点里再删才去掉。已读半透明只出现在重点，且不能露出后面的删除。

## 决定

- 星标写入本机 `focus-ids` 和条目副本 `focus-items`。全部 / 社媒 / X / B站 / 官方仍共用同一条记录和已读状态。
- 其他栏目左滑删除仍写 `isHidden`，已标重点的条目留在重点。
- 重点里左滑删除只取消收藏，不隐藏其他栏目。
- 已读下沉仍是所有栏目的排序；半透明只在重点。卡片正面用不透明底，半透明只作用在文字，避免露出删除。

## 验证

标为重点后，在社媒或 X 删除，重点仍能看到。在重点删除后，其他栏目不受影响。重点里已读条目变淡，未左滑时看不到红色删除。
