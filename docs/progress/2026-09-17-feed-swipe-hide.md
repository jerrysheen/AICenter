# 信息流滑动删除与收藏/引用可取消

## 目标

社媒列表左滑删除，且不和卡片上的收藏、引用按钮抢手势。收藏和引用再点一次可以取消。

## 决定

- 删除走 Feed `UserItemState.isHidden`，不物理删 ContentItem；手工帖用 `posts.hidden_at`。再拉取同一条不会重新出现。
- 滑动只绑在卡片正文上；`a, button` 仍走 pointer 排除，收藏/引用点击不触发滑动。
- 左滑露出的删除按钮在 `pointerdown` 时不再被「点空白处收起滑动」关掉，避免 PC 点击时卡片右移、click 落空。
- 收藏：已有对应灵感则 DELETE note。引用：已在草稿里则从 `referenceDraft` 拿掉。

## 后续

- 删除改为先从列表拿掉，后台 PATCH `isHidden`，失败再插回原位。
- 底部/侧栏点「总览」回到上次总览车道（社媒/股票/全球资产）和上次滚动位置；二级「总览」仍进枢纽页。

## 验证

左滑出现删除；点收藏/引用可反复开关。`npm run check`。
