# 帖子弹窗：点遮罩关闭、锁背景滚动、统一卡片操作

## 现象

- 只能点「关闭」关掉详情。
- 弹窗内滚动会带动背后信息流。
- 「打开原文」「翻译」一个像链接、一个像系统按钮，点击常打不开。

## 处理

- 点击 `<dialog>` 本身（遮罩）关闭；白卡片包在 `.dialog-panel` 里，内部滚动 `overscroll-behavior: contain`。
- 打开弹窗时 `body` 固定定位并记住 `scrollY`，关掉后还原，背后页面不跟着滚。
- 卡片和弹窗里的「打开原文 / 翻译」都用 `.post-link` 文本操作，不再用原生 `<button>` / `<a>` 混排。

## 验证

硬刷新后再点卡片脚注；弹窗内滚动、点灰色遮罩关闭。
