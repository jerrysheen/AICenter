# 主导航重复点击切换子页

用户要求总览首次点击进入信息流，继续点击主导航即可切换二级菜单；资产同样切换两个子页。用户随后确认末项是“日报”，不是完整日历。

## 行为

- 从其他主页面点击总览进入信息流；已在总览分组中，按当前选中子页继续轮换：信息流 → 股票 → 全球行情 → 日报 → 总览 → 信息流。
- 手动选中某个二级菜单后，下一次点击总览从该页继续。信源目录、完整日历和文章详情点击总览回到信息流。
- 从其他主页面点击资产进入持仓；继续点击在持仓和个人资产分析之间轮换。离开资产后重新进入从持仓开始。
- 桌面侧栏和手机底栏共用同一规则，其他主导航保持直接进入对应页面。
- 资产分析使用 `#assets/analysis`；`#assets` 及兼容的 `#assets/holdings` 进入持仓。手动点击资产二级菜单也写入浏览器历史，前进、后退和刷新按路由恢复所选子页。

先更新 `docs/product-v2.md` 的现行导航决定，再修改前端。该请求覆盖上一轮 UIUX 评审中“主导航总览固定进入总览”的决定；默认打开网站仍是 `#sources`。使用原有 `setView`、子页渲染及 API，没有增加后台能力或数据契约。
