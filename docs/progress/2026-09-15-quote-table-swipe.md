# 美股/亚洲观察表：表头、涨跌幅排序、整表横滑

## 目标

窄屏仍显示「标的 / 走势 / 最新价 / 涨跌幅 / 成交」，每只股票保持单行，表头与全部行一起左右滑动（隐藏滚动条），并可用涨跌幅排序。

## 决定

- 用一个横向滚动容器包住表头和列表，不按行独立滑动。
- 表格最小宽度 640px，列宽与桌面五列网格一致，避免小屏把标的折到第二行。
- 涨跌幅排序循环：默认 → 从高到低 → 从低到高 → 恢复默认。

## 改动

- `apps/web/public/index.html`：`#market-table-scroll` 包裹表头与 `#quote-list`。
- `apps/web/public/styles.css`：取消小屏隐藏表头；隐藏横向滚动条。
- `apps/web/public/app.js`：`changeSort` 与表头按钮。

## 验证

浏览器在约 390px 宽下打开美股列表：表头可见，行不换列，整表可横滑，点击涨跌幅会重排。
