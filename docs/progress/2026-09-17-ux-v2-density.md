# 2026-09-17 前端 UX v2：高密度阅读与安全落点

## 目标

按 Design 02 把页面从「信源目录 / 宽表格 / 测试按钮占首屏」改成可阅读的时间线与完整二级入口，同时修掉取消收藏删除灵感、保存副本静默截到 4000 字等问题。

## 决定

- 持仓三列、个人资产分析、工具宫格不重写；工具只增加「后台任务」入口，并隐藏未接通占位项。
- 官方文件仍只有元数据：阅读器明确说明没有正文，保存为带来源的灵感后再引用，不编造 content-item。
- 自动化只保存本机草案，文案固定为「草案已保存，自动化未启用」。
- 「重点」用本机标记，不把灵感 `pinned` 改成另一种含义。

## 改动

- `apps/web/public/`：总览时间线、信源目录/完整日程、行情名称+现价+涨跌同屏、账户五类指标两列、灵感卡片、会话预览、新提问材料、全屏阅读器、来源任务。
- `docs/product-v2.md`：总览定位与信息架构表同步。

## 未做

- 官方全文采集、真实调度自动化、系统推送、跨设备同步重点。
- 鸿蒙真机与字号压力验收。
