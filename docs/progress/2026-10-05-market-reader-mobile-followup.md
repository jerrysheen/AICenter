# 全球行情入口与手机阅读控件修复

## 修复

- AI硬件价格原入口错误挂在股票面板，且读取不存在的 `state.marketPane`。移除这段动态入口，在全球行情面板的资产分类上方加入常驻链接，使用既有硬件页面路由；即使外部行情加载中或失败，报价入口仍可用。
- 信息流文章共用阅读页的手机底栏顺序调整为“存入灵感 / 更多 / 返回”，返回位于右下角。沿用已有返回目标、筛选及滚动恢复，更多菜单仍能正确恢复触发按钮焦点。
- 媒体工具栏及来源筛选改成分行布局，避免来源框挤压“宏观与国际 / 科技产业”。来源框限制在容器宽度内，采用 16px 字号及至少 44px 触控高度；长来源名不撑开页面。保留浏览器缩放能力，未修改 viewport 缩放限制。

## 验证

- `scripts/verify-trendforce-routing.mjs` 扩展为 1188 / 320 / 375 / 390 / 430 / 502px：从全球行情实际点击硬件入口、长来源名宽度及字号、栏目完整显示、手机返回右侧位置，并保留报价快照、无历史、报告简介、来源切换晚返回的回归。
- `scripts/verify-uiux-reading.mjs` 验证阅读返回与筛选/滚动恢复、菜单焦点、手机底栏、既有页面响应式布局；菜单定位不再依赖其旧的最后一个按钮位置。
- 当前运行服务只读页面检查：硬件入口可见且加载 82 个报价卡片；真实媒体选择框包含 15 个选项，在上述六个宽度均无页面横向溢出，字号 16px，visual viewport scale 为 1。检查使用无头浏览器切换视口，没有模拟桌面操作。截图保存在忽略的 `.ai-data/trendforce-ui/`。
- `npm run check`：最终 763 / 763 通过（检查期间仓库其他工作新增测试，以最终结果为准）。

本次仅修改前端与回归脚本，当前运行服务已提供硬件 API，静态页面无需重启服务。手机 Safari 的原生选择器仍以真机验收为准；无头 Chromium 验证不能代替 Safari 真机行为。
