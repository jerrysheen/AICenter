# 自适应五栏应用壳

## 目标

在 HarmonyOS token 之上，按手机资讯/行情 App 的信息架构搭一套 Web / 手机共用的结构 UI，并用 mock 填行情、工具、问答。

## 决定

- 底栏五栏常驻：信息、行情、工具、问答、账户。对应截图里的首页 / 自选 / 基金 / 私募 / 我的，名称换成我们自己的。
- `<840vp` 用底部页签；`≥840vp` 用同一组入口的侧栏，不另做一套桌面信息架构。
- 信息页：搜索 + 分类 Tab + 特别关注 + 信息流。真实 posts 和 mock 故事按分类混合。
- 行情页：统一行高列表（名称 / 代码 / 最新价 / 涨跌幅），数据全部示例，不接下源。
- 工具页：宫格占位，仅「快速发布」「设备连接」可点。
- 问答页：建议问题和输入条，提交只记在当前页，不调用模型。
- 账户页：承接原配对、指标和设备撤销。

## 改动

- `apps/web/public/index.html`、`styles.css`、`app.js`、`mock.js`
- `apps/web/src/server.js` 增加 `/mock.js` 静态资源

## 验证

- 去掉特别关注后，信息页为分类 Tab + 列表。
- 行情整体改名为交易；子页签为股票 / 持仓 / 全球资产 / 流水。
- 交易页右上角改为搜索标的（全球股票与比特币占位）。
- 持仓、全球资产、流水为后续自动同步交易数据预留容器。
- `npm run syntax` 通过。
