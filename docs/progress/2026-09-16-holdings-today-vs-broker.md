# A股今日改走券商当日口径

## 目标

刷新后各行浮动盈亏已接近券商，但首页「A股今日」仍对不上截图里的「当日」。

## 决定

- 券商「当日」是现价对昨收 × 数量（港股通再乘当前汇率），不含把昨收市值按昨天汇率重估。
- Yahoo 历史收盘折人民币会把港币汇率变动算进「今日」，A 股今日会比券商当日高出约一千多。
- `moveGroups` / `moves` 的「今日」改为该组持仓 `dayPnlCny` 之和；周 / 月仍按原持仓市值波动。
- A 股汇总行增加当日、浮动，方便和券商顶栏核对。港币汇率仍是 Yahoo，浮动大约差几十元。

## 验证

- `npm run check`：A/B 股今日优先用 `dayPnlCny`，不跟历史序列走。
