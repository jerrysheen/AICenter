# 信息流测试补上作者页暂停标注

2026-10-21。#191 合入后，信息流翻页、后台刷新和作者列表的测试报 `feedTagRefreshPaused is not defined`。

`apps/web/public/app.js` 里这个函数和 `loadXFeed`、`loadXueqiuFeed` 在同一个文件。页面加载这一份脚本时能调用到。作者页打开时它返回真，后台刷新就不去查标注。线上脚本没有缺这个函数。

失败来自测试。这些测试用正则从 `app.js` 抽出加载函数，放进单独的沙箱执行，没有把 `feedTagRefreshPaused` 一起带上。沙箱里没有页面的其余函数，所以一调用就报未定义。抽取时把这个函数带上之后，作者页仍会跳过标注，其他信息流仍会查。

不改页面行为。不新增 migration。当前 schema 仍是 95。下一号是 96。空号仍是 63、79、80、82。不要重建数据库。Web 和 Worker 都不用为这项重启。
