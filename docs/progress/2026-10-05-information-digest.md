# 2026-10-05 信息摘选

## 目标与决定

用户授权小时提炼“明确的信息句＋ref”，日报只做去重、更新与排序。按来源发布时间（缺失时入库时间）归属，不能声称实际事件发生于同一小时。展示简短，冻结依据完整。

先新增稳定设计 `docs/information-digest-v1.md`。旧 DailyBrief V1/V2 与分析阶段兼容保留，新生产 Worker 明确注入信息摘选 Service，继续使用同一 Harness closedContext，不新建 Agent 或 Runtime。

## 改动

- 新 Contract：逐条提炼输出、InformationItem、固定 snapshot/hash/version 的引用、HourlyDigest、严格生成与查询输入及类型。旧字符串分析改名为 LegacyDailyAnalysisOutput。DailyBrief 新增完整 informationItems/hourlySnapshots，旧前八项仅为概览；目录条数读取完整清单。
- 前向 migrations 38/39：不可变小时快照、运行租约及当前发布指针；旧数据库不删除、不重建。事项写入、发布指针与各自 Outbox 同事务。失败恢复可重新发布已有有效版本，历史日报重写不替换较新小时结果。
- Domain：每小时读已存材料，分批绑定段落，验证引用属于实际读过的批次。失败续跑；预算未读量明确，下次继续缺失批次并保存新版本。默认检查最近24个已结束小时，旧迟到材料支持指定小时。重复文本合并引用；模型编排的未知/重复ID拒绝，未选事项自动保留。
- 日报用自身冻结材料补齐小时事项，复用相同输入的阅读，编排简短句子；非整点截止用独立边界快照。持续关注只更新明确启用的问题，先选择相关事项再读原段落。超出单轮预算的清单分批整理，未完成跨批语义去重/全局排序时明确说明，保留全部事项。
- Worker 显式注册 report.hourly.extract 与每小时 interval schedule。HTTP 手动生成仅桌面入队。Ask 新增两个只读 Domain Tool：时间窗口分页摘选、定向读取冻结证据；问题决策仍交给 Ask，不加 Router。
- 日报页新增小时查询、最近24小时入口、逐条信息清单与版本证据；来源直接展开原段落和邻近上下文、原站入口。首页1000字符展示预算保留完整句子，全文入口不删除其他信息。问答来源栏可打开冻结小时快照，日报第八条以后的事项也能引用。
- 新增可重复的真实 Harness 合成样本验收脚本，运行记录只写 Host 忽略目录。

## 遗留与使用

正常重启现有 Web/Worker 后才加载新路由、注册任务和前向迁移，下一整小时检查最近24小时；现有日报保持旧稿，手动生成或后续定时生成采用新流程。日报页“小时信息摘选”可以指定已结束小时、读信息句和展开来源；Ask 可按时间窗口先读事项，再读依据、按需搜索。

真实来源提炼质量、跨批语义去重、长期任务费用/耗时与手机实际排版尚未持续验收。段落身份校验不等于句子语义正确，合成样本成功不能据此宣布正式新闻提炼全部通过。此工作不替代0.2.0隐私、安全与稳定性验收。
