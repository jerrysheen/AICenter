# 底栏改灵感与总览留白

## 目标

底栏五项与侧栏同一组入口；总览有图标；社媒不再占一级；Compact 总览看板不要挤成两列。

## 决定

- 一级入口顺序：总览、灵感、问答、资产、工具。
- 社媒只留在总览二级。灵感从工具提出，一级页不再显示「返回工具」。
- Compact 总览看板纵向堆叠，模块间距 16vp；`≥600vp` 才并排，间距 24vp。
- 底栏选中态用一级文字色，不用品牌蓝；页签文案 12fp。总览图标用 `house`，灵感用 `lightbulb`。

## 改动

- `docs/product-v2.md` 信息架构表。
- 网页导航、图标清单、总览栅格、工具页入口。

## 验证

窄屏底栏五项图标齐全；灵感一级可写；总览双卡有间距。`npm run check`。
