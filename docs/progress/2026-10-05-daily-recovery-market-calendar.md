# 日报成稿超时与沪深行情日期修复

## 目标与原因

用户反馈日报失败，A/B 股行情与闭市、节假日状态不可靠。
只读检查运行记录确认：2026-10-05 社交/新闻已完成，最后 editorial 阶段重复超过180秒；
自动重试与延迟补跑均未成稿。此前有效日报和已完成阅读阶段仍保留。
行情端存在两个问题：沪深开闭市仅按工作日9:30–15:00判断；雪球报价时间被丢弃，
Source 将获取时钟填成 asOf。假期中的前次报价因此显得是当天实时数据。

## 决定与改动

- 继续使用同一Worker、Harness、Service、Repository、Contract；不添加Agent或改历史migration。
- 阅读/追踪阶段仍180秒，编辑成稿360秒；编辑精简重复元数据和覆盖索引。
  完整原文、证据、覆盖保留在冻结快照，阶段调用每分钟续租，SDK客户端按请求截止隔离。
  同流程版本的阅读缓存保留，失败恢复只执行成稿。
- Domain纯函数统一沪深A/B股交易日与午休，2026年节假日来自
  [上交所年度公告](https://www.sse.com.cn/disclosure/announcement/general/c/c_20251222_10802507.shtml)。
  调休周末仍休市，年度未核验时工作日返回unknown及空的后续开市时间。
- 雪球timestamp与Yahoo marketTime经Source透传；无报价时间时asOf为null，
  获取时间继续单列。持仓和市场附带calendar，持仓附带quoteAsOf/session。
  页面展示休市原因、下次交易及详细报价时间，休市卡片标明最近交易日变动。
  港股个券保留香港供应商状态，未把沪深假期套到香港报价。
- 保留用户已有工作区改动，未提交、重建数据库或改写历史冻结行情。

## 验证

- 真实运行数据库在线备份副本续跑：仅调用一次editorial，输入20654字节，
  163015毫秒成稿、7个主题；原材料与之前完成的阅读阶段全部复用。
- 实际取A股、沪市B股、深市B股：来源报价均为2026-09-30，而非获取当天。
- 服务重载后实际API显示国庆休市、下次交易2026-10-08 09:30；
  持仓25条均保留真实报价时间，沪深与港股时间/状态保持分离。
- 增加假日/调休周末/年度未知、竞价/午休/收盘边界、报价时间端到端与Yahoo回退、
  成稿续跑/阶段截止/续租、SDK超时隔离回归。
- 初次 npm run check：676项测试通过；随后补充Yahoo回退时间测试。
  工作区已有B站工具历史允许未打标字幕直接读取的改动，使旧API测试的“0条”断言过时；
  更新为验证返回同一条已保存字幕，保留已有信息流实现。
- 最终 npm run check：680/680通过（包含同期工作区新增回归），语法、类型、架构、Harmony检查通过。
- 生产服务通过原本机重启入口重载，随后经已注册日报Job执行resume；
  2026-10-05实际成稿7个主题，analysis与Job均completed，GET可读。

## 限制

2027年的交易所节假日尚未录入和核验；不能按政府工作日推断。
旧日报的冻结行情保持原版本；报价日期修复适用于新的读取和新材料快照。
真实成稿验证保持原文证据规则，不代表已独立外部核验材料陈述。
