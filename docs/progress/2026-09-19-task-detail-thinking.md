# 任务详情在轮询间隙显示思考中

## 目标

2.5 秒刷新的是服务端 progress/steps。打开详情时，客户端要能看见「正在思考下一步 → 出一条结果 → 再思考」的过程，而不是一块静止文字。

## 决定

- 不改轮询间隔，不新增 progress SSE，也不改 schema。
- 状态为 `open` / `claimed` 时，进展区和步骤列表在已有结果后追加「正在思考下一步」占位，省略号步进、行本身轻闪。
- 最后一步是 `started` 时，该步本身当作当前思考；变成 `done` 后占位挪到下一条。
- 终态后去掉占位。

## 验证

- `test/work-package.test.js` 锁住思考占位与动画类名。
- 只改 `apps/web/public`、`docs`、`test`，立刻生效，不弹进程。
