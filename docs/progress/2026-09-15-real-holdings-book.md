# 真实持仓账本

## 目标

用截图中的 A 股、港股通、B 股沪/深持仓替换交易页示例数据，落盘后按实时行情和汇率核算，并方便以后增删批次。

## 决定

- 批次账本是 `holding_lots`（V7），现金是 `portfolio_cash`。第一次打开持仓时从 `manual-holdings-book.js` 导入；之后以数据库为准，不再覆盖用户改过的现金和仓位。
- 市场分层：`a_share`、`hk_connect`、`b_sh`(USD)、`b_sz`(HKD)。港股通现价是港币，券商成本和市值栏是人民币；市值按 `HKDCNY` 折算，成本不再乘汇率。沪 B `90xxxx.SS` 用美元，深 B `20xxxx.SZ` 用港币。
- 行情走 Yahoo spark；缺代码进入 `missingQuotes`，需要补 Adapter 而不是让页面直接调供应商。
- 顶部三行：A 股、B 股沪市、B 股深市，各为股票 + 现金 + 合计。大字 CNY，外币小字；不展示汇率卡片。
- 数据盘：今日 / 本周 / 本月**原持仓**波动，对照昨日 / 上周 / 上月；期间新买入单独列出。导入仓 `openedAt` 为空时仍按现仓回算。现金和加仓表单先收起。

## 验证

- `npm test` 含 holdings 核算、缺行情标记与 API 落盘
- 浏览器交易 → 持仓：A/B 合计、汇率、现金、筛选、详情删除、添加批次
