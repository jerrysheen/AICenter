# 持仓波动拆原仓 / 新买入

## 目标

回退持仓汇总金色样式；区间涨跌不再把转入资金和新买入当成原持仓收益。

## 决定

- 顶部三行和今日/本周/本月数据盘回到灰色卡片。
- `HoldingLot.openedAt` 进入契约和 V9 `holding_lots.opened_at`。导入账本为空，表示开仓日未知，期间仍按**当前仓位回算**，页面标明未扣转入本金。
- 之后新增的批次写入开仓日。`moves.pnlCny` 只含期初已有仓位的价格/汇率波动；`addedPnlCny` 是期间新开仓从开仓价到期末的波动。
- 现金仍是余额快照，只计汇兑。转入本金要等 `Transaction` 和现金流水，不能从当前现金倒推。

## 验证

- `npm run check` 含原仓/新买入拆分用例和 schema V9
