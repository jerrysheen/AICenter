# 总览行情条在手机宽度上价格分开

## 现象

393 宽的总览 `#sources`，日间四列是上证50、创业板50、科创50、恒生指数。A 股指数现价带着四位小数（例如 `2768.2732`）时，18px 的价格比格子宽，数字画进下一列，看起来贴成一串。涨跌幅仍是分开的。1280 宽的侧栏格子更宽，同样四位小数也能分开。

## 决定

总览行情条的现价用 `formatStripPrice`，固定两位小数、不分组。`2768.2732` 显示 `2768.27`，`2402.8855` 显示 `2402.89`，恒生 `23525.97` 不变。涨跌幅、红绿色和四列结构不动。股票页和别的行情仍走 `formatPrice`，来源给出的小数位留着。

## 验证

`node --test test/market-placeholders.test.js`

用页面样式在 393×800 和 1280×800 量过：四位小数时相邻价格间隙大约 2.5px，两位小数后大约 23px。1280 两位小数间隙大约 30px。

## 部署

不新增 migration。当前 schema 仍是 98。下一号是 99。空号仍是 63、79、80、82。不要重建数据库。需要重启 Web，浏览器再加载一次。Worker 不用为这项重启。
