# 信息流切换页面后保持滚动位置

## 现象

在信息流下滑浏览后切到问答、工具等页，再回来会回到列表最顶部。

## 原因

各业务页共用窗口滚动。切走后当前页变短，浏览器把 `scrollY` 压到 0；信息流 DOM 还在，但回来时已经从顶部开始。

## 处理

- 离开页面前记下该页 `scrollY`；信息流额外记下当时靠近顶部的卡片 id。
- 回来后还原滚动；高度变化时用卡片锚点对齐。
- 已加载条数 `feedShown` 仍留在内存，不因切页重置。
- 改范围/平台筛选仍重置分页并回顶。

## 验证

信息流下滑一段 → 问答或工具 → 再回信息流，应停在离开前附近。`npm run check` 通过。
