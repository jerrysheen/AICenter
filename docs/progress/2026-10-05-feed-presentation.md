# 信息流入口与正文排版

## 目标

按用户要求把 B站移出信息流，保留字幕工具；X 与雪球合并阅读入口；正文轻度排版，评论另起一行。

## 决定

- 使用已有社媒列表、来源标签、字幕 API 与 Capture / ContentItem，不增加 Agent、Job、表或页面 Contract 字段。
- 信息流、重点、最近和总览内容推荐排除 B站；已有数据库、星标、浏览记录与引用不删除。B站通过工具访问已存字幕与链接采集。
- 社媒入口合并 X / 雪球；平台独立采集范围仍在信源维护中选择。旧平台浏览状态自动映射到新入口。
- 正文与评论只在显示时拆分，不重新分析或改写已存原文、译文、哈希与 AI 材料。

## 改动

- 顶部去掉 X / 雪球 / B站独立入口与平台筛选；B站字幕加入工具网格，从社媒信源目录移出。
- 字幕详情查找独立于当前信息流筛选；工具读取已存字幕允许没有 Tag，继续遵守隐藏状态。
- 展开卡片、详情页和原译文对照共用社媒排版：保留段落、列表，长段落只在完整句子边界分段；数字、股票代码和链接不切碎。
- 识别已有独立评论标题及逐条标记，每条评论独立显示；未抓取图片/视频提示保持单独附注。无评论不添加评论区。
- 折叠卡片的正文摘要排除评论，另外显示评论数量；正文与评论均转义不可信 HTML。
- 新翻译提示要求保留段落、评论标题、作者与逐条换行；不批量重译历史条目。
- 更新 product-v2 / contracts-v1，保留工作区已有媒体、日报和行情等其他改动，未提交 Git。

## 验证

- 初始只读抽查最近 100 条社媒原文，46 条带既有评论标记，5 条存在超过 320 字的单行段落。运行中的 Worker 会继续改变最近样本，不把此数字写成全库总数。
- 排版、HTML 转义、旧浏览状态兼容、重点/最近投影和字幕详情查找均有确定性测试；字幕服务与 API 缓存及隐藏行为有回归覆盖。
- `npm run check` 全部通过，681/681 测试通过，包含语法、Source / Harness 语法、Contract typecheck、architecture / Harmony 校验。
- 当前 Web 返回新 app.js / markdown.js / mock.js / styles.css，四项 HTTP 200；健康接口和字幕读取接口 HTTP 200。
- 未使用 Computer Use，也未模拟桌面输入；没有进行桌面或鸿蒙真机视觉验收。

## 运行状态

静态界面通过既有资源指纹热更新，刷新可读取本轮排版。核对时 Worker 正在执行日报与信息流 enrich，未为本轮界面调整中断这些任务。服务端的未打标字幕读取策略与新翻译提示已经修改并回归通过，现有长驻 Web / Worker 在下次正常重启时加载；本轮没有触发运行中任务的进程重启。
