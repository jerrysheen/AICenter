# 联合早报国际栏目接入

## 决定

第一阶段只接国际栏目，进入现有宏观频道，不另建中国、新加坡、财经或全站任务，也不做历史回填。本机普通 HTTPS 访问下，`https://www.zaobao.com.sg/news/world` 返回 200 并重定向到 `https://www.zaobao.com/news/world`，规范地址与用户入口一致，页面没有 RSS。实际入口因此定为 `https://www.zaobao.com/news/world`。两个官方域名都留在白名单里，文章身份用路径中的 story ID，不把换域名当作绕过。

来源显示名是「早报」，频道仍是宏观与国际。列表和正文走独立 HTTP 适配，Yahoo 浏览器读取保持原路径。抓取、清洗、时间和去重都是确定性代码，不新增翻译。中文稿沿用现有“已是中文则不送翻译”的判断。正文进入当前新闻列表时复用既有质量门。

## 边界

每 60 分钟检查，每轮最多 20 条新索引、5 篇新正文，同源并发仍为 1，请求间隔 3 秒。这些值写在来源配置里；未配置的来源保持原来的轮次行为。48 小时窗口只用带时区的发布时间，或在列表没有精确时间时用路径日期判断这一天是否已经整个落在窗口外。路径日期不写入 `publishedAt`。列表上的“19:54”“58分钟前”也不写成精确时间。正文时间优先取 JSON-LD 的 `datePublished`，保留 `+08:00`。

页头“订阅新闻速递”和页尾“购买此文章”单独出现时不判付费墙。明确的不可免费访问、付费/登录提示才记为付费限制，且不改走浏览器。DNS、空页、挑战页、403、429、模板变化和正文缺失分开记录。429 在有界等待内尊重 Retry-After，超时则暂停该来源本轮后续请求。

## 验证

合成测试覆盖栏目过滤、跨域去重、置顶旧闻不截断扫描、未知时间、正文去噪、短文完整、长预览、普通订阅、付费限制、挑战页、403/429、模板变化，以及 Yahoo 列表仍走浏览器、BBC 正文规则不变。

相关命令：

```text
node --test test/zaobao-world.test.js test/media-ingestion.test.js test/media-expansion.test.js test/media-public-news.test.js test/media-channel-ingestion.test.js test/media-reading.test.js test/media-body-audit.test.js test/media-feed-loading.test.js test/media-reader-session.test.js
```

92 项通过。验收使用系统临时目录里的新数据库，没有写入生产库，也没有重启服务或调用付费模型。

实机国际列表 200，27 条世界栏目链接。三轮强制同步分别新增 20、7、0；第三轮 `not_modified`，27 个 story ID 无重复。正文抽了 3 篇，均为 `full` / `structured_body`：

- `https://www.zaobao.com/news/world/story20261007-9800683`，姜贵瑛，`2026-10-07T21:26:48+08:00`，15 段
- `https://www.zaobao.com/news/world/story20261007-9800344`，页面无个人署名，`2026-10-07T19:54:55+08:00`，3 段
- `https://www.zaobao.com/news/world/story20261007-9796956`，页面无个人署名，`2026-10-07T18:41:33+08:00`，6 段

同一次对照里，BBC World 与 Guardian World 的 RSS 标题更多落在非洲、拉美和欧洲社会新闻。早报这一页更集中在东亚安全、霍尔木兹/红海能源运输、美伊和韩国防务网络事件，并用中文通讯员稿补上英文世界栏目里没有的首尔、冲绳视角。诺贝尔化学奖、特朗普与普京通话、乌克兰空袭和美国死囚个案与 BBC 标题有重叠。这是同一时刻的标题对照，不是覆盖率结论。

本机实例已启用，来源名是早报。随后按用户要求同时收国际和中国栏目，不收新加坡。两个栏目都用同一套正文适配。每轮索引和正文上限提到 80，请求间隔仍是 3 秒。补抓后国际 28 篇、中国 35 篇都有正文，没有新加坡文章。后续每小时任务会自己再扫这两个栏目，并把新文章的正文读完。配置模板里的 `enabled` 仍是 false，新安装不会自动打开；本机数据库状态是已启用。
