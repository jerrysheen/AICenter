# X 卡片：打开推文、收藏灵感、正文排版

## 目标

真实时间线可用之后补小交互：点作者打开推文、右侧收藏进灵感、正文保留换行；拉完关掉采集标签，并拿掉示例卡片。

## 决定

- 作者名链到 `sourceUrl`（推文，不是主页）。
- 收藏调用已有 `POST /api/v1/notes`，正文带作者、推文和链接；不改 notes 表结构。
- 拉取结束后关闭本次使用的 Chrome 标签，不退出整个 Chrome 进程（登录还在用户配置里）。
- 翻译不在本轮做：需要模型 Connector、凭证和 Worker，不能把 Grok Key 放进页面。

## 验证

- `npm test`、卡片打开推文与收藏按钮可点。
