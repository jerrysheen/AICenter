# 社媒不再假显示「正在翻译」，左滑删除重新可见

## 目标

远端信息流里「爱吃折耳根的Ace / Sac / 周览资源」等卡片一直停在「正在翻译…」；社媒左滑后看不到删除。

## 决定

- 本地没有挂住的翻译 Job。这些卡片多半是中文正文夹英文专名，启发式误判后，标题被无条件换成「正在翻译…」。
- `needsZhLocalization` 以汉字为主时不再送译；只有真正在跑翻译时才显示「正在翻译…」。
- 信息流正文不再做成 `button`，左滑手势不再被标题区域吃掉。
- 删除时好时坏的原因：星星 /「展开」会吞掉手势；红钮露出来后 `pointer-events` 仍可能是 none；翻译重绘会拆掉已滑开的卡片。手势改挂在整行，露出后即可点删除，重绘后按条目 ID 恢复滑开状态。

## 验证

信息流里上述作者显示原标题，不再整卡「正在翻译…」。从标题、展开或星标一带向左滑都能看到红色删除，点得下去。`npm test -- test/localize-texts.test.js`。
