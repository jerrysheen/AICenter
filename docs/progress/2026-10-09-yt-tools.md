# 2026-10-09 YouTube / B 站音轨转写

这是现有 B 站 AI 字幕拉取之外的本地补充。没有平台字幕时，可以下载音轨再在本机转写。不改浏览器字幕任务，也不自动排队。

脚本在 `tools/yt-tools/`。虚拟环境和成品在用户目录 `yt-tools/`：`venv` 里是 yt-dlp 与 faster-whisper，`output` 放 MP3、字幕和转写结果。Windows 用已安装的 Git Bash 运行 `dl_mp3.sh`。

本机已有 Python 3.13.2。新装 ffmpeg 9.0.2、deno 2.9.7。yt-dlp 为 2026.08.19。没有 NVIDIA 显卡，转写用 CPU int8。

短视频测试用了 Blender 的一分钟公开片 `https://www.youtube.com/watch?v=RJnKaAtBPhA`。下载得到 60.07 秒、1,719,590 字节的 MP3，并保存了英文 srt。本地 medium 模型转写出 4 句，时间落在 6.9 秒到 16.3 秒，和平台字幕的大致位置一致，个别词不同。转写成功后删除音频和分段中间文件，只保留文字。
