# 未配对退出与重新扫码

## 目标

解决二维码无效、已使用、过期或设备授权失效后，鸿蒙薄壳已经进入 WebView 却无法返回扫码页的问题。

## 流程

1. Web 配对或会话校验失败时显示独立的未配对阻断页，不再展示可操作但无权限的业务页面。
2. 阻断页和已配对设备的设置页都提供“退出并重新扫码”。
3. Web 先调用 `POST /api/v1/session/logout` 清除 Cookie，并在存在设备身份时撤销旧设备。
4. Web 优先调用 `AICenterShell.resetConnection()` 原生桥接，鸿蒙薄壳立即清除保存的服务器地址并返回本地扫码页；`aicenter://reset` 保留为后备。
5. 普通浏览器不调用原生能力，留在明确的“连接已清除，请重新扫码”页面。

## 安全边界

- Web 只能触发固定的 reset 动作，不能要求原生层打开任意地址或执行任意命令。
- 配对失败后从地址栏删除已经失效的一次性配对码，刷新页面不会反复兑换。
