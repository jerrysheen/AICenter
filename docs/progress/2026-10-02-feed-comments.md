# 2026-10-02 X 与雪球评论摘录

## 目标

抓取 X 和雪球信息时，把当时看得到的前几条评论写进正文。

## 决定

- 只取前 5 条。每条保留作者名和最多 240 字，接在帖子原文后面，格式是「评论」加「· 作者：内容」。
- 不新增 Feed 字段。标题和摘要仍用帖子原文，不含评论段。
- 雪球走已登录浏览器里的评论 JSON。回复数为 0 时不请求。旧接口没有评论列表时再试 v3。7x24 用去掉前缀后的数字 id。
- X 只在首页能看到回复数大于 0 时打开 status 页，取主帖后面的前几条回复。补全文或长文时如果人已经在 status 页，顺手读评论，不重复打开。回复数为 0 不打开。
- 已经入库的 external ID 仍会跳过，不会为了补评论重抓旧帖。身份指纹按带上评论摘录的入库正文计算。
