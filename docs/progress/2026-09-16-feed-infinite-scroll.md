# 信息流：下滑加载更多，详情关闭后回到原位置

## 现象

- 「信息」一次列出全部卡片，列表过长。
- 点开详情再关掉，页面经常回到顶部，找不到刚才那条。
- 根因之一是 `showModal()` 会先把 `scrollY` 清掉；之二是弹窗 `close` 时背景锁有时没解开。

## 处理

- 信息流先渲染 12 条，滑到底部或看见「下滑显示更多」再追加 12 条。
- 打开弹窗前记住 `scrollY` 和卡片 id，再 `showModal()`。
- 关掉详情后还原滚动；弹窗 `open` 属性变化时再确认解锁背景。
- 切换范围 / 平台时重置分页并回到顶部。刷新列表时尽量保持当前滚动。

## 验证

硬刷新信息页：计数为「已显示 12 / N 条」。下滑出现 24 条。点一条详情再关闭，滚动位置与打开前相同。`npm run check` 通过。
