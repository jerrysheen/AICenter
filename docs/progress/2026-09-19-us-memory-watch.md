# 美股观察池补存储，并与亚洲上市代码分开

## 目标

美股分览能看到海力士、闪迪的美股报价；韩股三星 / 海力士仍只走亚洲看板。

## 决定

- 美股观察池只收美股上市代码，亚洲观察池只收 KR/JP/TW 本地代码。同一公司可以两边各挂自己的代码，不能把 `000660.KS` 一类韩交所代码放进美股。
- 海力士美股用纳斯达克 `SKHY`；闪迪用纳斯达克 `SNDK`。韩交所 `000660.KS` / `005930.KS` 留在亚洲「韩国存储」。
- 三星没有可用的美股报价（OTC `SSNLF` 成交和高低价不可用），不硬塞进美股观察池。
- Catalog schema 拒绝跨市场代码；搜索加入自选也按上市后缀分流。

## 验证

- `node --test test/market-catalog.test.js`
- 美股「算力链」出现 SKHY / SNDK，不再出现 `000660.KS` / `005930.KS`。
- 亚洲「韩国存储」仍是海力士、三星的韩交所代码。
