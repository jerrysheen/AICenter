# 重载搜索状态、简报后退和简报骨架行高

2026-10-21 体验官复查 `v=cacfb2c5fe97`：搜索状态、高亮、加载更多、快速输入、大部分骨架和「返回日报」都通过。还有三处。

手机宽度下，信息流整页重载后会停在「搜索中…」和骨架上，点不了，其实没有在搜索。简报骨架和一次真正的搜索在手机模拟里比桌面慢，那是模拟把主线程和网络拖慢，不是状态标错。标错的是重载这一条：上次的搜索词存在本机，页面重新打开时写回搜索框，但没有把这一轮标成正在请求，也没有发出搜索。阶段却把「词还在、请求没发出」当成正在搜索，列表就不再画。现在只有请求真正在飞时才显示「搜索中…」。恢复出来的词先用已经在手里的条目画出列表；来源还在读时写「正在读取内容…」，不写没有匹配。重载不会为了补一次搜索把整表再换成骨架。

桌面用浏览器后退回简报，滚动仍比离开时多大约 58px。「返回日报」走的是页内那条，不受影响。浏览器会自己再恢复一次滚动，而且离开简报时页面标记已经换掉，简报条的粘性样式卸了，这时再量锚点会把位置记偏。现在一打开页面就由本页自己记滚动。切走简报之前先记下当时的 scrollY；简报已经不在当前页时不再重记。从别的页面退回来只用这个 scrollY，页内「返回日报」仍用原来的锚点。简报树里的滚动锚定也关掉，避免内容一换浏览器再把滚动推一截。标题栏盖住的行，以及只从底边探出一点的高行，仍然不当锚点。

桌面简报骨架行高是 112，和信息流两行标题一样，真实简报条目大约 160，内容换上时会跳。信息流骨架仍是 112。简报、小时报列表里的骨架行改为 160，标题条改为三行的 72。
