# 持仓列表当日盈亏与横向滑动

## 目标

交易持仓表按券商持仓页补上「当日盈亏」（金额 + 涨跌幅），窄屏时整表左右滑，方式和看盘表一致。

## 决定

- 页面列仍用已有 `HoldingsPosition.dayPnlCny / dayPnlPct`，相对昨收 × 数量再折人民币，不改 Contract。
- 列顺序：名称/市值、持仓数、现价/成本、当日盈亏、盈亏比、浮动盈亏。
- 持仓表复用看盘的 `market-table-scroll`：内层固定最小宽度，表头和行一起横滑。

## 验证

- `npm run check`
- 浏览器交易/持仓：当日盈亏与现价涨跌方向一致；手机宽度可左右滑。
