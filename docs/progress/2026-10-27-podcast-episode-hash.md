# 2026-10-27 播客单集 hash 切换不再空白

从 `#podcasts` 点开一集，或从别的页把地址改成 `#podcast/<id>` 时，列表里的这一集往往已经是「已整理」但还没有正文。阅读器先清空 `#page-root`，再按 `element.children` 找 `.podcast-article`。浏览器里这是 `HTMLCollection`，没有数组的 `find`，于是抛 `TypeError`。页头还没挂回去，主区域就空着。点选发生在写入地址之前，所以地址会停在 `#podcasts`。整页刷新时目录还没在内存里，先画出「正在读取这一集…」，正文回来后再画，所以刷新是好的。

现在按集合本身有没有 `find` 来读子节点，没有就先转成数组。没有正文的已整理单集仍先画出标题和「正在读取正文…」。宽屏目录默认收起、页头随滚动离开这两项不动。

不新增 migration。需要重启 Web，浏览器再加载一次。Worker 不用为这项重启。
