# 2026-09-27 问答分享图排版

## 问题

分享图按整段重新折行。加粗、链接把第一行撑短，或长链接在词中断开时，后面的行仍从行中间起笔，并叠到下一段上。有序列表只画圆点，只有上边框的页脚会被画成整圈。

## 决定

- 每一行沿用页面已经排好的行框，不再用 `measureText` 重排整段。
- 字体用元素自己的 computed font，字号和字重才对得上。
- 有序列表画序号，无序列表画圆点，都对齐第一行。
- 边框按实际上、右、下、左分别画。`overflow` 不是 `visible` 的区域裁切，避免超长回答盖住页脚。
