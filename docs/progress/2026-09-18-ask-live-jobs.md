# 问答后台继续与进行中状态

## 目标

离开问答会话后 Worker 本来就会继续跑，但页面把轮询绑在当前 DOM 上，再点进去没有进度，其他入口也看不出有任务在跑。同时输入条盖住回答步骤。

## 决定

- 不改单 Agent / 一次一条 Worker：多问入队，不并行抢 Runtime。
- `GET /api/v1/agent/runs` 列出 `queued` / `running` 的 `ActiveAgentRun`；会话列表带 `pendingRuns`，会话详情把未完成 Job 投影进 exchanges。
- 前端全局轮询这些 Run，记录列表、会话进度、底栏/侧栏圆点和离开问答后的提示条都读同一状态。
- 会话页改成整页滚动，输入条跟在线程后面，不再锁 `body` 滚动。

## 验证

- `npm run check`
- 浏览器：提问后切到总览应看到进行中提示；再进该会话应继续轮动步骤；可再问一条进入排队。
