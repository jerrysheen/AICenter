# 2026-09-19 问答页 PC 会话骨架

## 目标

PC 网页上问答会话的输入框和正文不在同一列：会话区左对齐，输入条按整页居中并 `position: fixed`，中间留下大块空白。

## 决定

- 列表和会话共用 `--ask-column`（800px）居中。
- 会话层把标题栏 + 主区收成一列：线程自己滚动，输入条在列底。
- 宽屏输入条回到文档流，不再按视口左右拉满后单独居中。
- 窄屏仍贴底固定，保留键盘抬升。

## 验证

`npm test -- test/ask-session-layout.test.js`
浏览器：宽屏打开一条问答，正文与输入框同宽对齐，输入条贴在列底而不是悬在页面中间。
