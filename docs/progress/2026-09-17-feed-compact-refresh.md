# 信息流摘要列表、译文前置与刷新当前页

## 目标

社媒「全部来源」一屏看更多条；点进详情才看全文。已翻译条目在列表和详情里都先看到中文。顶栏可强制刷新当前一级页面。

## 决定

- 列表只保留作者行、标题（最多两行）和一段摘要。标签、原文、打开原文/翻译放进详情。
- 有译文时：列表标题和摘要用译文；详情里译文在原文之前。
- 「全部来源」按条目时间混排，不再先堆完 B 站再堆 X。
- 顶栏刷新只重拉当前页已缓存数据（不触发 X「拉取 50 条」浏览器抓取）。

## 验证

社媒列表应变短；已译推文先显示中文摘要，点开后译文在原文上方。点刷新应提示「已更新当前页」。`npm run check`。
