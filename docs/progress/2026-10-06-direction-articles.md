# 简报方向文章

## 用户决定

依据本轮提供的检查稿与离线预览，将新稿主阅读单位改为“方向→报告期→一篇文章”。预览的人工重排和数字来源样本仅作设计参考，没有写入生产正文或伪造成站内来源。先更新信息摘选设计，再修改现有 Service、Contract、Repository、Worker 和 Web；仍使用同一冻结 DeepSeek Harness / Elucid Grok，没有新增线程或 Agent。

## 实现

- `brief-editorial-v3` 保存稳定方向 key/label、文章标题、短导语、小标题、自然段，每段引用实际采用的原事项，由程序继承不可变证据。同一事项可支持同一文章的不同章节、必要段落和导语，跨方向重复主要归属、未知 ID、标签错配、无依据导语整份拒绝；语义正确性仍需人工核对，不把存在的 ID 当成证明。
- 编辑提示先做主次取舍，保留关键新增信息、数字期间、计划状态和作者归属；完整财务表、公司履历与名录回原文，个人持仓日记与自算未公布业绩通常留底稿，作者研究选核心论点及两三个支撑数字，单条重大传闻不因刺激程度进入标题/导语。编辑输入以短编号关联全部事项与来源，返回后还原真实 ID，提供受12KB预算约束的完整只读冻结段落及缺失数量，缺依据保持未知，不开放工具、联网或 Host 权限。
- ready 复用同时比较编辑版号与全部事项指纹，模型阶段缓存包含完整输入与指令哈希；纯重编的快照身份也包含编辑指令，避免调整编辑要求后仍复用上一份重编结果。固定小时 Job 支持指定完整小时/冻结快照的 rewrite，复用底稿、不重抓/重译/重提炼，写新不可变快照，失败保留旧 ready 指针；失败重编可继续重试，旧 v2 主题及日报版本可读。常规小时保持提炼14分钟/编辑6分钟，纯冻结重编允许编辑12分钟，均受原20分钟总预算约束。目录计数对 v3 为文章数量，底稿搜索仍保留全部事项。
- 小时模式默认最新可读时段，仅渲染当前方向，切方向保持窗口；没有该方向准确显示空态，不借其他时段补齐。日报保持正式冻结稿语义；历史主题稿明确标识旧稿，不伪造新版段落证据。
- 新文章组件独立于旧 itemRow：自然段内44px来源入口，冻结段落依据为次级菜单，整篇收藏/引用。小时引用使用冻结 snapshotId/articleId，仅解析所选方向文章，缺失不回退整小时，旧整小时引用仍兼容。方向有键盘切换与独立位置保存；来源返回保持方向/时段/位置，阅读中的新版本只提示，主动接收后保留选定时段。
