# 2026-09-19 X 来源任务暴露「抓取50条」

## 目标

X 来源任务里的自动化设置只是本机草案，用户需要一个会真正执行的入口：抓 50 条新内容，并翻译、打 Tag。

## 决定

- 自动化草案继续只写 `localStorage`，不启动定时调度，也不显示「自动运行中」。
- 「X 来源任务」、信源目录菜单和自动任务页增加「抓取50条」。
- 该动作走现有 `GET /api/v1/feed/x?refresh=1`、翻译和 Worker 标注，不新开调度器。
- 刷新时把已入库 `externalId` 传给 X Connector，时间线跳过旧帖并继续下翻，尽量凑满 50 条新的。

## 改动

- `packages/database`：`listCaptureExternalIds`
- `packages/domain`：refresh 时把已知 ID 放进 Source context
- `packages/connectors` / `packages/source`：采集跳过已入库推文
- `apps/web/public/`：菜单入口与抓取 → 翻译 → 打 Tag 流水线

## 遗留

定时自动化仍未接入。时间线见底时可能凑不满 50 条新内容。
