# 简报数据恢复与阅读减法

用户先要求接入已有可溯源信息摘选，再明确先完成恢复、后修复阅读界面。引用任务已实现链路并验证合成样本，但未写生产摘选；本轮读取运行服务和保存检查点，发现后续批次失败导致整小时不发布成功结果。最初小时目录为零，已有10月5日V2日报7条。

## 数据恢复

- 保持Report Service、Repository、Contract和固定Worker handler边界。后续模型批次超时、断线或校验失败时，发布已经证据校验的成功批次，保留未完整读取计数与警告；没有成功批次则继续失败，不把失败变成空小时。
- 历史失败/租约失效的恢复优先使用原冻结输入和匹配检查点，先发布已有成功批次，后续处理补齐未读材料及迟到材料。输入无匹配成功检查点时仍正常准备材料。第一批未知段落引用继续拒绝，不改模型预算、执行器、频率、过滤规则或迁移。
- 通过启动器正常加载服务，再经已有桌面小时生成API派发固定Job。16—20点四个小时恢复187条摘选，逐一验证158组唯一小时证据的段落、材料版本与哈希；既有7条日报及7组原成稿段落引用均可读。未直接修改生产数据库或生成示例数据，日报原版本保留。四份结果仍有未完整读取材料，不能宣称全天处理完成。
- 小时读取清单按有效租约表达运行状态；过期运行记录作为失败读取，保留原发布版本，不在GET中写库。

## UI减法

- 顶部仅保留小时更新/日报精选文字切换、日期、更多。使用全站刷新；日期内显示已发布历史日期，删除独立检查更新和往期按钮。
- 搜索、未读、收藏、处理数量/时区/检查时间、设备说明、管理生成操作收进更多。每条默认显示正文与来源，已读/收藏/引用在逐项更多里使用。
- 沿用信息流页边距、颜色、浅分隔线，移除整页圆角框和内层卡片；正文保持16px，不裁掉句子或限定语。小时按时间/信息句/来源阅读，无结果只显示短空态和已有日报入口，正在整理只对应有效运行状态。
- 日报先显示日期、真实导语和原文内容，冻结/成稿/统计窗口进入折叠说明。700px以下移除重复前三条的速览。旧V2逐项证据适配为共享阅读行，保留原body与原成稿引用；`renderAnalysisBrief`另提供简洁兼容模式，缺逐项证据的历史稿仍保留sections正文和引用，去掉套卡及首屏技术信息。
- 加载状态在搭建与视图/日期切换之前设置，先显示读取态，避免已有稿件闪成尚未发布。无可读小时但有已存日报时优先读取日报。来源弹层、阅读位置、版本提示、搜索、收藏与已读功能保持。

- `npm run check`：语法、类型、架构、Harmony及758/758测试通过。专项覆盖失败后部分发布、冻结检查点恢复、迟到材料、未知引用拒绝、有效/失效租约。
- 无头合成浏览器13宽度×2视图通过，包括375/390/502首屏、工具折叠、历史日期、旧V2简洁模式、原文弹层与滚动、修订提示、离线恢复、晚到响应、授权清理。普通读取和更新检查只GET。
- 用真实运行服务和真实日报进行只读无头浏览器验证，375/390/502px、740px高。小时正文顶部约191px；日报正文分别353/353/325px，底栏顶部682px，正文16px。无横向溢出，无JavaScript异常；日期内选择历史稿、工具说明和来源可用。人为延迟真实日报GET并观察DOM，未出现尚未发布闪现。
- 诊断、真实页面截图和检查日志只放在忽略的`.ai-data/brief-live/`、`.ai-data/brief-data-check.log`。页面与接口已由常驻服务提供，不留待用户重启步骤。真实手机系统、软键盘与剩余材料提炼语义仍未完成验收，0.2.0停止线不改变。
