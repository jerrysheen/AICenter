# HarmonyOS 设计指南落地：主页改版

## 目标

按 `docs/design/harmonyos-design-guides.md` 的可落地 token 和响应式架构，重做第一版网页主页，先看视觉与导航效果，不改 API 与配对逻辑。

## 决定

- 色彩改用宇宙蓝 `#0A59F7` 与雪域灰底，文本用四级透明度，不再用绿色杂志风。
- 字体阶梯对齐 PC：标题 18–22 / 700，正文 14，说明 12；卡片圆角 16，按钮 20（大屏 12），弹出层 32。
- `≥840vp` 使用侧边导航（信息流 / 快速发布 / 连接），入口有扩展，不是把底栏原样挪到侧面。
- `<840vp` 使用底部页签；选中态用中性黑胶囊，侧栏当前项用品牌蓝满铺。
- 标题栏 56vp，毛玻璃 + 1px 分割线；间距只走 4/8 倍数。

## 改动

- `apps/web/public/index.html`：应用壳、侧栏、底栏、分视图。
- `apps/web/public/styles.css`：HarmonyOS token、断点栅格、深色同名 token。
- `apps/web/public/app.js`：视图切换，保留原有 session / 发布 / SSE ID。

## 验证

- 桌面 ≥840：左侧导航、品牌蓝选中胶囊、雪域灰底、白卡片 16 圆角、信息流三列。
- 快速发布、连接（二维码 + 24h 指标）、详情半模态（32 圆角 + 模糊遮罩）可用。
- 390 宽：侧栏隐藏，底部页签「信息流 / 发布 / 连接」切换正常；配对与发布逻辑未改。
- `npm run syntax` 通过。CSS 有 5 分钟缓存，页面链了 `?v=harmony-3` 以便立刻看到新样式。
