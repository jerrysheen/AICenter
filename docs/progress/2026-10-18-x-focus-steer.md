# X 推荐方向打分与自动点赞

2026-10-18。For You 抓取时不再逐条点开详情和评论。先滚动收集卡片文字，按 `config/x-focus.json` 的 7 个方向打分，只展开相关度达到 0.75 的帖，每轮最多 8 条。分数和一句理由写入采集元数据。自动点赞默认关闭。

## 打分

方向固定为：美股大盘、半导体与科技美股、Polymarket 及政要发言、油价大宗与地缘、企业动态、GPU 等硬件价格、AI 公司。油价权重 3，其余为 1。相关度取各方向分数的最大值。主方向按分数乘权重选取，所以油价在分数接近时优先。

每批最多 20 条，只要求 JSON。整批解析失败，或某一条无效，才逐条再问。`AI_CENTER_HARNESS_HOURLY_PROVIDER=google` 时走现有小时报的 Gemini flash-lite 和密钥轮换，任务标记为 `x-focus`。否则直接请求 `gemini-3.1-flash-lite`，不使用小时报里的 Grok 或 DeepSeek 模型名，也不走会回退到 Grok 的翻译或搜索路径。翻译仍只用 Gemma 26B，搜索仍只用 Grok。

缓存键是推文 id 加配置版本，落在已有的 `daily_analysis_stages`（`report_date=x-focus`）。关键词预筛不写入这份缓存。打分超过剩余时间，或剩余不足 3 秒，整批改用关键词；关键词命中记 0.8，只用于决定是否展开，不自动点赞。打分抛错时本轮不点开任何帖。

## 自动点赞

环境变量 `AI_CENTER_X_AUTO_LIKE` 默认关闭。页面「推荐记录」里还有一个开关，存在 `runtime_snapshots` 的 `x-auto-like`。两个都打开才派发。

每轮 X 入库后，从当天附近、相关度至少 0.75、JEV 保留、模型或缓存打分、非敏感、不是政要本人发言、没有点赞任务的帖里，按权重分取一条，派发已有的 `feed.x.like`，来源记为自动。敏感包括选举党派、战争伤亡、仇恨、成人、加密喊单和争议人物。核对账号、唯一原帖、登录墙和弹窗、点后重开核验、不重试、重复点赞不取消，都沿用原来的点赞任务。

默认每天最多 20 次、每小时最多 5 次、两次至少间隔 2 分钟，按 `jobs` 里来源为自动的 `feed.x.like` 计数，并用推文 id 去重。可用 `AI_CENTER_X_AUTO_LIKE_DAILY`、`AI_CENTER_X_AUTO_LIKE_HOURLY`、`AI_CENTER_X_AUTO_LIKE_INTERVAL_MS` 收紧或放宽。同一时间仍只有一个未完成的点赞或取消点赞。登录墙或页面被拦截会立刻关掉页面开关并写明原因。连续两次结果未确认同样停止。用户再打开页面开关会清掉停用。

取消点赞是新的 `feed.x.unlike`，只在「推荐记录」里由用户点击。原先未点赞不会点击。它不改变「重复点赞不取消」的保护。

## 页面

X 工具条的「推荐记录」按推荐和关注分开画最近 14 天的方向命中率（方向分至少 0.5 的条数除以当天条数），灰色虚线是当天已确认的点赞次数。某一天比此前最多 7 个有数据的日子的均值低 30% 以上，且至少有 3 天可比较时，页面给出提示。记录列出自动和手动点赞，以及手动取消。页面不展示内部分数字段名。

## 部署

不新增 migration，不新增 npm 依赖，不需要 `npm ci`，不要重建数据库。需要同时重启 Web 和 Worker。确认要自动点赞时，再把 `AI_CENTER_X_AUTO_LIKE=1` 写入环境，并在「推荐记录」打开开关。方向和阈值改 `config/x-focus.json` 的版本号后，旧缓存不会复用。
