# 交易页：字号、涨跌色、图标按钮

## 目标

收紧手机行情密度；涨跌幅表头与其它列表头一致；标题栏图标不再走系统 emoji；涨跌红绿能在总览和列表同时显示。

## 决定

- 金融涨跌改用 `data-up / data-down`，不再和 `warning / confirm` 混用同一套语义。
- Compact 列表主文案 14fp、说明 11fp，对齐设计指南 caption / body，不再用 16–20 当手机默认。
- 图标按钮统一 SVG，覆盖 hover / pressed / focus；`button` 去掉系统 appearance，避免鸿蒙 Web 把「涨跌幅」画成原生按钮。
- 总览指数卡、领涨领跌共用 `.up / .down` 文字色；观察表涨跌幅用文字色，持仓胶囊仍用底色。

## 改动

- `apps/web/public/styles.css`、`index.html`、`app.js`

## 验证

- 浏览器交易页：总览指数涨跌有红绿；美股/亚洲行价格与涨跌幅有颜色。
- 涨跌幅表头是文字+排序图标，不是系统按钮。
- 设置/搜索/加号为描线图标，按下有灰底反馈。
