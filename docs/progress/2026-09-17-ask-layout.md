# 问答页列表与移动端排版

## 目标

问答列表把「开始提问」和历史记录分开；历史以标题为主并有日期分隔。会话详情在窄屏自动折行，不再需要缩小页面才能看完整回答。

## 决定

- 列表层：顶部入口卡片 + 「历史记录」分组；条目只保留标题和时间，按天分隔。
- 会话层：提问 / 回答分区；长词、表格、代码在容器内折行或横向滚动，不撑开整页。

## 改动

- `apps/web/public/index.html`：问答列表结构。
- `apps/web/public/app.js`：列表渲染与会话问答分区。
- `apps/web/public/styles.css`：列表分隔、会话自适应。

## 验证

`npm run check` 通过。浏览器：列表为「开始提问 + 按天分隔的标题」；390px 下历史详情正文与引用 chip 不再横向撑开页面。
