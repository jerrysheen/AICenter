# 2026-09-18 对照设计预览：信息架构与页面结构

## 目标

以 `preview (1).html` 为交互基线，先对齐产品语义和页面结构，而不是先调边距字号。

## 决定

- 一级频道改为 **总览 / 信息流 / 股票 / 全球行情**。「社媒」只保留为内容类型和信息流筛选项。
- 宽屏继续使用底部五项导航，不再切成 220px 左侧栏。
- 总览桌面构图改为左侧行情+日程、右侧最新内容；市场原生数据仍留在下方。
- 信息流全局筛选改为 **全部 / 重点 / 社媒 / 官方**。官方条目由 StaticSignalBoard 投影，不写入 Feed 表。
- 默认排序仍是收录顺序 + 已读下沉；「按发布时间」是显式切换。
- 星标 = 本机重点；存入灵感仍在阅读页，两者分开。
- 搜索匹配用户看到的中文译文与标题，不只搜原文。
- 进入信息流也会加载官方信号板，官方筛选项不再依赖先打开总览。
- 阅读、信源、日程、行情、任务、灵感、账户、持仓改为独立 hash 页面；官方全文只走现有 `policy.official-detail` Source。

## 改动

- `apps/web/public/`：壳层、总览、信息流投影、独立页面、设置入口层；本轮补齐页头 52px、全宽主栏、底栏始终可见、卡片 8px、弹窗 20px 圆角与图标关闭。
- `apps/web/src/routes/source-routes.js`：新增 `GET /api/v1/official-detail`，内部读取已有官方详情 Source。
- `docs/product-v2.md`：信息架构表与频道命名同步。

## 未做

- 官方全文仍取决于 Source 是否真能读到正文，不编造。
- 自动化仍是本机草案，不显示「自动运行中」。
- 任务中心读取本机 Runtime jobs；手机端看不到 Worker 细节，这是现有安全边界。
