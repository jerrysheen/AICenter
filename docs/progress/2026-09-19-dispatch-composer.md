# 灵感底栏改成分发输入框

## 目标

附图预览不再走未带凭证的 `/content` 地址（浏览器会显示 not found）。输入框改成豆包那种：`+` 里选图片，左侧芯片分发到灵感、任务或对话。

## 决定

- 随记和任务共用一个底栏输入框，不再各放一套「附图」按钮。
- `+` 只展开菜单：图片；灵感目标下另有 AI 加工。
- 芯片在 灵感 / 任务 / 对话 之间切换。对话只发文字，图片仍只挂到灵感或任务。
- 选图后立刻用 `URL.createObjectURL` 出缩略图；已保存的图用带设备凭证的 fetch 再转成 blob。上传失败时缩略图还在，发送时再试一次。
- 鸿蒙分享仍写入 `#note-body` 和隐藏来源字段。

## 验证

- `npm test -- test/attachment.test.js`
- 在灵感页点 `+` → 图片，确认缩略图不是 not found；芯片切到任务或对话后再发送。
