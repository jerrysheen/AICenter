# UIUX 阅读、导航与反馈整改

根据用户提供的 2026-10-05 TradingPlus 体验评审实施。保留白底、蓝色强调与既有页面结构，范围是现有功能的可用性和稳定性。

## 实现与决定

- 桌面文章使用约 40em 阅读宽度和靠近正文的固定返回、阅读设置、更多操作。手机阅读隐藏主导航，使用返回、存入灵感、更多三项底栏，点击区至少 48px，留出安全区及正文底部空间。
- 阅读字号可在 16–24px 调整。更多菜单保留重点、引用、分析、保存及原文入口；菜单关闭恢复到触发控件，后台重绘后仍能恢复焦点。
- 普通导航进入浏览器历史，返回使用本应用的历史项；直接文章链接缺少来源时返回信息流。兼容带斜杠的 hash 路由；启动读取完成后刷新文章结果，缺失文章不会停留在加载状态。
- 保存并恢复信息流平台、分类、搜索、排序、日期范围、列表规模与滚动位置；媒体和社媒阅读沿用原有内容投影及语言稳定策略。
- 主导航“总览”固定进入总览。子页面返回标签写明目的地；搜索入口注明当前范围，在已有独立搜索的页面避免重复入口。
- Ask 历史、信源目录、日历、知识库和量化实验室明确区分读取中、空数据、错误、成功，错误提供重试。日历来源不可用时提示读取不完整。问答会话的迟到响应不能覆盖后来打开的会话；新提问保留输入区域。
- 工具入口移至分红策略卡片前方，异步卡片扩展不会改变工具点击位置。视频工具补齐图标，未开放项使用明确标签，问答使用“新提问”。
- 信息流限制桌面卡片宽度，整理移动端元信息；总览左侧卡片减少空隙，横向筛选增加边缘提示；日报内容先于折叠配置说明。
- 灵感空白输入在未聚焦时收起工具行，卡片末行使用稳定的操作列；软键盘视口变化时隐藏底部导航并抬升输入区。
- 稳定币列表保留名称、数值两列，数值右对齐并使用等宽数字。资产增长图按实际容器宽度重绘，保留 12px 坐标文字；分析页和持仓页共用金额隐藏设置，隐藏时不显示分析图表或账本金额。
- 通用交互补齐可见焦点、选中及禁用状态。

共享反馈函数位于既有 `app.js`，量化页面通过依赖注入复用。复用已注册静态资源及资源版本更新，不为界面更新重启 Web / Worker。没有增加 Agent、Job、Contract 或 migration；保留工作区其他任务的已有改动，未提交 Git。

## 验证

- 最终 `npm run check` 全部通过：719/719，包含语法、契约类型、架构与 Harmony 检查。新增 8 项确定性回归覆盖路由、历史回退、浏览状态恢复、历史加载合并、错误重试、会话竞争与量化页面状态。
- `scripts/verify-uiux-reading.mjs` 使用实际前端、独立本机临时 HTTP 服务与合成 API 数据，在无头 Chromium 中通过：媒体和社媒各连续 5 次阅读返回，筛选及滚动恢复，浏览器前进，直接文章链接及刷新回退，信源目录斜杠路由及刷新，桌面和移动菜单焦点恢复。
- 阅读布局覆盖 390 / 430 / 768 / 1188 / 1440px；九个主要页面在上述五种宽度没有整页横向溢出；资产图表额外覆盖 360px。慢响应、失败、空结果、重试、迟到会话响应、异步工具位置、数字列及金额隐藏均通过。
- 模拟 visualViewport 键盘覆盖时，灵感输入区上移且主导航隐藏。该检查不代替真实手机键盘验收。
- 已目视检查合成文章的桌面与手机截图，未使用真实资产或私人灵感。未使用 Computer Use 或模拟桌面输入。
- 当前服务的首页、app、量化、样式、图标及依赖资源均 HTTP 200，返回本轮代码；健康接口 HTTP 200。全量运行状态显示仍有后台任务，本轮未触发进程重启。
- 本轮涉及文件的 `git diff --check` 通过。检查期间社媒规则与测试有并行更新，初次全仓出现 5 个失败；更新后的相关测试复跑 17/17，通过后再执行最终全仓检查，不将并行业务改动计为本轮实现。

浏览器脚本需要 Host 环境提供 `UIUX_RUNTIME_PACKAGE`（包含 Playwright 的 Node runtime package.json）和 `UIUX_BROWSER`（Chromium 可执行文件），执行 `node scripts/verify-uiux-reading.mjs`。合成截图与日志只保存于 `.ai-data/`。

## 仍需用户执行

- 至少一台 iOS Safari 与一台 Android Chrome：系统返回、地址栏伸缩、横竖屏及真实安全区。
- 360 / 390 / 430px 真机的拇指触达、筛选末项、文章末尾及关闭控件。
- 问答和灵感真实软键盘、长 URL、200% 缩放、系统放大文字与焦点/提交按钮可见性。

上述项目仍是发布验收项，本轮浏览器与单元测试通过不代表手机真机或 0.2.0 整体发布门槛通过。
