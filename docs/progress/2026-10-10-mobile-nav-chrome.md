# 手机底栏总览回首页，标签条吸顶

## 根因

手机底栏「总览」从 `#feed` 进 `#market`，不是点击穿透，也不是恢复上次子页。`readLastOverviewTarget` 没有被调用。底栏和侧栏共用 `primaryNavTarget`：已经在总览这一组时，再点「总览」会按二级菜单向后轮换。信息流的下一项就是股票。

手机上标题栏本来是 `position: sticky`。总览二级标签条只在简报页吸顶，其他页跟着正文滚走，往回滚一点仍然在视口外，要回到顶部才出现。

## 决定

- 底栏「总览」一律打开 `#sources`。侧栏仍按原来的二级菜单轮换。资产底栏切换不变。
- 宽度小于 1200px 时，标题栏改成不透明实底，总览二级标签条吸在标题栏下面，和简报页同一套。往回滚时导航还在，不必滚到顶。

没有后端改动，不需要重启。

## 验证

`npm run syntax` 通过。`npm test`：1074 项，通过 1063，失败 10，跳过 1。失败仍是分析方法登记哈希、信息树政策、Node 22.14 缺 zstd、本机无 Cursor CLI。无头 Chrome 390px：下滚 1800px 再回到 1500px，标题栏停在顶部，总览二级标签条停在标题栏正下方。
