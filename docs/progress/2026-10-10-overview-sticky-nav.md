# 总览吸顶与侧栏回首页

## 根因

手机信息流的「全部 / 重点 / 最近 / 社媒 / 官方 / 媒体」在 `.channel-bar` 里，跟着列表滚走。小时报的「日报 / 小时报」行是吸在总览二级标签条下面的。

股票和全球行情的横向行情卡会从二级标签条右端「简报」旁露出来。窄屏给 `.market-tabs[data-more-right="true"]` 加了右侧渐隐遮罩，总览二级标签条也带 `market-tabs`，遮罩把吸顶条右端打成透明。

侧栏「总览」仍走 `primaryNavTarget` 轮换。上一轮只让手机底栏固定打开 `#sources`。

工具页第一行说明没有上边距，贴着吸顶标题栏，上沿被挡住。

## 决定

- 宽度小于 1200px 时，信息流筛选行吸在标题栏加二级标签条下面，实底，和小时报那一行同一套位置。
- 总览二级标签条不用右侧渐隐遮罩，吸顶层保持不透明背景和高于正文的层级，盖住横滚行情卡。
- 侧栏和底栏的「总览」都打开 `#sources`。资产和其他主导航的轮换不变。
- 工具页说明文字加 12px 上内边距。

没有后端改动，不需要重启。

## 股票和全球行情仍漏

窄屏二级标签条用负外边距贴齐页面边，背景盒仍只有内容区那么宽，右侧大约两个页边距没有不透明底。股票横滚指数卡和全球行情表都伸进这截空白，下滚后涨跌数字从「简报」右边露出来。

宽度小于 1200px 时，吸顶二级标签条的宽度改成内容区加两侧页边距，并去掉 `.market-tabs` 的 `max-width: 100%` 限制，背景盖住整行。标题栏本来就是整宽。没有后端改动。
