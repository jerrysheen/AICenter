# 从详情返回简报

## 原因

手机按返回时，简报里打开的一条，或从简报再打开的阅读页，会回到进入简报之前的页面。同一小时里换条目用的是替换当前历史，列表没有单独的一条。带 `node` 的地址如果是直接打开的，历史里也只有这一条。小时地址若写晚了，还会把阅读页那一条历史改掉。

## 决定

同一小时、同一天，从没有条目到打开一条，改为新增历史。再换另一条仍替换当前这条。`#report?hour=20&node=…` 这种地址进入时，先把不带 `node` 的列表放在下面，再压上这一条。状态里用 `aiCenterReportList` 记住，避免返回时再插一次。

页内「返回小时报」「返回日报」在有这条标记时调用浏览器返回。返回到不带条目的地址时，清掉打开的条目并重画列表，不再写一次历史。

当前地址已经不是 `#report` 时，简报不再 `pushState` 或 `replaceState`。

不新增 migration。当前 schema 仍是 95。下一号是 96。空号仍是 63、79、80、82。不要重建数据库。需要重启 Web，浏览器再加载一次。
