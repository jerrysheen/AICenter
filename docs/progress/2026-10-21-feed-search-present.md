# 搜索呈现和简报骨架

2026-10-21 体验官在线上 `2d69cd2` 复查：简报返回、骨架和搜索能用。搜索进行中会先闪「共 0 条 · 没有匹配的已收录内容」，条数随本地命中边读边涨。空结果还挂着「继续读取文章…」。标题没有标出关键词。搜「AI」时条数是全部命中，列表只画出第一窗，底下没有加载更多。桌面简报只有「正在读取简报…」。手机简报和信息流会先清掉骨架，再花一截时间把列表接上。桌面信息流的骨架行比两行标题的真实行矮。桌面从简报详情返回时，滚动锚点把贴在标题栏下面的那一行当成可见，位置差大约一根底栏的高度。

现在两个字及以上的搜索在请求结束前只显示「搜索中…」和信息流行高的骨架，不写共 0 条，也不写没有匹配。被后来的输入取消的请求不会把这一轮标成结束。请求结束或失败之后，条数才落定：窗口没画完是「已显示 n / N 条」，并且底部是「加载更多」；全部画出是「共 N 条」和「已经到底了」。空结果只说明没有匹配，不再继续读取文章。标题里的关键词用标记高亮。关键词不在标题里、而在正文或摘要里时，另起一行摘录，摘录里也标出关键词。标题已经命中时不另起摘录。

信息流和快讯先在画面外把列表拼好，再一次换上，骨架留到这一帧。简报第一屏、日报读取和小时报骨架都用同样的行高。小时报外面仍留着原来的慢读标记，十秒后还能重试。返回简报时，标题栏、简报子导航和简报条盖住的行不再当作滚动锚点。
