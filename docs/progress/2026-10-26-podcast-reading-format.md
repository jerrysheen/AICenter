# 2026-10-26 播客阅读页头与整理格式

窄屏单集阅读不再把标题、频道、「打开 YouTube」、状态和速读切换整块吸在标题栏下面。这些内容留在正文前面，向下滚就离开屏幕。离开这段页头之后再向上滚，才固定露出一行：返回、单行标题、速读切换。宽屏仍用原来的吸顶页头。

Gemma 整理新的一集时，章节按论点写成短段，关键句加粗，并列内容写成列表。「要点」仍在全文前面，不再要求每一段都以「主持人：」开头。时间仍写在 `## 主题（HH:MM:SS）` 里，阅读页把时间放到标题下面。已经落库的正文保持原样，只有新跑的整理才带这套格式。分节提示词变长之后，长视频一段最长 7840 字、最短 5174 字。同一档样例仍是 6 段、14 次调用。

没有新增 migration。需要同时重启 Web 和 Worker，浏览器再加载一次。
