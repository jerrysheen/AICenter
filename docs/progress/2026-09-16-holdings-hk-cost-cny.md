# 港股通浮动盈亏按人民币成本核算

## 目标

券商持仓页「今日涨幅」和我们的当日盈亏能对上，但「浮动盈亏」对不上。

## 决定

- 国泰海通 A 股账户里带「港」的标的（中芯国际、速腾聚创、新奥能源、岚图汽车）是港股通，不是独立港股账户；仍记 `hk_connect`，汇总进 A 股那一行。
- 券商成本栏是人民币单价，现价才是港币。市值 = 港币现价 × 数量 × `HKDCNY`；成本 = 人民币成本 × 数量，不再乘汇率。
- 当日盈亏仍用现价对昨收（都是港币）再折人民币，所以原先看起来是对的。
- 通信 ETF 种子成本改为截图中的 `1.022`。已落盘的账本以数据库为准，不会被种子覆盖。

## 验证

- `npm run check` 含中芯国际 `costCny = 500 × 60.703`，不乘港币汇率。
