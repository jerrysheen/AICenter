# 信息流与报告

小时报按入库时间入选，主时间和排序也改用 `firstIngestedAt`。没有入库时间才用发布时间。比当前时间晚超过两分钟的时刻仍退回另一个时间。发布时间早于本小时窗口时，行上另写「发布于 HH:MM」；不是同一天则写「发布于 M月D日 HH:MM」。`timely=false` 的条目放进默认收起的「旧闻补录 N 条」，不和本小时命中混在一起。总览小时列表只留 timely 命中。

信息流每个范围都经过 `channelForFeedScope`。点「媒体」或 TrendForce 时 `channel` 写成 `media`，快讯写成 `flash`，社媒写成 `social`。切回全部时，重点、最近和官方保持原样。快讯列表不再因为 channel 停在 `flash` 而被画出来。

日报不再读已经停更的 `daily_report_briefs`。`GET /api/v1/reports/tree/latest-daily` 只取已发布的日报：`published_id` 为空的草稿不算，最新一期还是草稿时返回上一期已发布的。查询按 `start_at` 取最新一份，不受七日目录限制。卡片最多读前 5 个根节点。同一工作区的结果缓存 60 秒；新一期日报发布后清掉这份缓存。首页 bootstrap 和简报页都读这一份。bootstrap 同时保留 `brief`，和 `daily` 指向同一张卡片。正文不带模型名。

小时变化，或在日报和小时报之间切换时，浏览器历史 push 一条。同一小时里换条目只 replace 当前记录。地址已经是目标哈希时不再写，所以后退不会再被换成新的一条，也不会从小时报直接回到 `#inspire`。

快讯在 Worker 入库时整理正文。开头是 `【…】` 时，括号里的文字作为标题，并从正文和摘要里拿掉。没有括号、而标题又是正文开头时，标题留空。这次不回填已经入库的旧标题。灵感卡的副标题不再重复卡片标题；正文开头和标题相同的一行也会拿掉。问答预览先去掉成对的强调标记和行首的 `>`、`#`，再按字符截到 180 字；`snake_case`、`a > b`、`#1` 留着。读出旧预览时同样处理。
