# 2026-09-19 X 来源任务重新露出关注抓取

## 目标

X 来源任务只剩一颗「抓取50条」，默认范围是「为你推荐」，看起来像不再抓关注博主。

## 决定

- 来源任务里先选「正在关注 / 为你推荐」。打开弹窗时落到正在关注；按钮写成「抓取关注 50 条」或「抓取推荐 50 条」。
- 采集仍走现有 `GET /api/v1/feed/x?feed=following|for-you&refresh=1`，不新开调度器，也不做 B4 关注同步。
- 浏览器首页若点不进目标栏，返回 `feed_tab_mismatch` 并停止入库，避免推荐栏被当成关注。
