# JEV 保存价值闸门 V3

2026-10-05 用户决定：采集留底 → JEV 保存价值 → ContentItem → 现有 AI Tag。
质量与兴趣独立。没有命中 Tag 不表示没有价值；后续可从已完成打标但无命中的内容整理新 Tag。
最新用户决定覆盖二选三：当前 Instance 直接 enforce，三项正向分数全部 >= 0.60 才进入 ContentItem 和新闻可读池。
此规则是用户选定的使用策略，不冒称通过独立样本验收。保留历史原文与旧评分，另生成新规则报告。

## 判定

主问题：忽略兴趣范围、来源名气与新闻重要程度，材料是否至少提供一项值得保存的实质信息？
具体事件、数据、产品变化、可复用方法、经验、带明确条件和现象的问题线索均可；普通快讯也可。
生产规则 `all-three-0.60`：reading_value / specific_content / sufficient_information 三项全部 >= 0.60 才 KEEP；0.60 本身通过。advertising 不否决。
有效、无关键缺失的输入不满足规则则 DROP。已确认关键缺失、模型缺上下文 >= 0.60 或技术异常仍 REVIEW；未确认的关键续帖在不通过时 REVIEW。
旧 `calibrated-value` / `two-of-three-0.60` 仅保留回放与显式兼容，不用于当前生产。enforce 下只有 KEEP 可建 ContentItem/进入可读池，DROP 拦下，REVIEW 原始 Capture 待补不放行，接口失败也不能绕过三项条件。
请求不包含 readingScope、条目 Tag、topic_relevance、来源名气；不改 Agent Quality 的检索相关性规则。

已确认关键缺失或输入/接口异常 → 技术待定或待补；主判断足够明确 → KEEP/DROP；其他 → 语义待定。
旧校准规则未校准或失配保持 REVIEW。新规则通过显式配置执行，不把 productionQualified 改成 true。分数不是经过校准的真实概率。
新安装默认仍 shadow；当前 Instance 按用户指令 enforce。V1/V2 与原 V3 回放保留，不能改写旧分数冒充新请求结果。
五问、模型和输入不变，规则重算可以复用原 V3 分数，必须标明未重新请求 JEV；评分缓存键不因后置判定策略改变。

## 输入

主帖、已确认同作者同线程续写、理解主帖必要的已确认引用分别保存并共同评分；普通评论不参与。
同作者依据稳定账号 ID/handle，线程依据已核验回复/引用关系；显示名不能恢复正文。
历史评论只有文本时记录疑似续帖，不宣称完整；疑似关键续写不能被低保存价值直接淘汰。
采集元数据保存缺失对象、是否影响核心信息与依据；已知截断、未展开长文、关键线程缺失先保护。
图片/视频仅作展示时不阻断独立有价值的正文。缺失诊断单独读取附件和采集状态。
结构化元数据属于 Capture，不进入页面供应商字段；不改已执行 migration。

## 回放与兼容

A：旧 V2 概率本地移除范围门槛，仅为带兴趣请求的对照。
B：仅修输入，以原 V2 问题/范围重新评分变化项，对照输入影响。
C：新保存价值定义、无主题请求，使用主判断校准；不复用 V2/B 缓存。
旧 200 条属于已见回归/校准材料，质量、完整性、兴趣分栏，争议不强迫放行。
新样本在评分前从旧 200 条以外分来源选定，冻结规则后才评估；AI 辅助标注不称人工真值。
审计产物留 Host runtime；HTML 不嵌入全量原文，避免恢复巨型单行源码导致客户端卡顿。
媒体与社交分别统计；生产媒体索引、正文均接入同一 gate，先保留原始索引/正文快照，再判断可读池与 ContentItem。
媒体从摘要升级正文会重新评分，并可解除质量排除；排除不写用户隐藏状态。后续 AI Tag 仍按既有流程执行。
历史重分类经 Domain Review Service 校验当前输入与旧评分输入完全一致才更新 Capture metadata；改变输入的记录不复用旧分数。
Repository 可读查询与日报材料查询排除已应用的 enforce 拦截；当前 all-three 策略下 DROP 与 REVIEW 都退出可读池。REVIEW 保存 captured 状态的原始 Capture 待补，不新建内容。此操作不删除历史原文、ContentItem、译文、Tag 或阅读状态。

入选池只返回当前规则明确 KEEP 的采集，未评分旧内容不能靠“没有DROP标记”入选。实时抓取空池不回退未通过的Source Snapshot。一次更新由显式 `feed.quality.refresh` Worker Job 执行：每个社交来源取当前阅读池同等上限200条，媒体取现有索引；只复用模型/问题/当前输入指纹完全一致的评分，否则重新请求JEV。更早历史原文保留但未经现行判定不入选。刷新与新采集均经Service/Repository/Outbox，不在HTTP里执行长评估。

页面主信息流和首页推荐直接使用实际通过的内容，空池显示空状态，不补示例材料。Tag 是后处理，未打 Tag 不隐藏合格内容。媒体浏览缓存升级版本，避免旧缓存暂时回显未通过材料；采集保存事件触发防抖刷新。用户主动收藏与阅读历史保留，历史原文仍能按显式引用读取。
