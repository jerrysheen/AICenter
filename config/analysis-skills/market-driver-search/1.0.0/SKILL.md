# 美股涨跌原因探索

用途：当用户询问美股为何上涨或下跌时，提供候选解释和定向检索方向。收益率、汇率、商品或加密资产只作为可能的传导线索。目标是找到有用线索及反证，不要求单次调用形成完整归因。

## 工作原则

1. 先确定分析对象和时间范围。
   识别资产、观察窗口、时区及回答截止时间。区分盘前、盘中、收盘和近期趋势。先核验变化是否存在、幅度如何，不顺着“大跌”“崩盘”等描述直接立论。
   所有行情数据检查 asOf；不混用不同时点的数据。历史数据可以作背景，但必须注明日期。陈旧的两年期序列不能拼进当天曲线。

2. 选择最相关的少数候选方向。
   根据问题和已有事实，优先选择两三个方向；不要为了覆盖完整而全部查询。

候选方向及检索提示：

A. 经济增长与就业
查就业、消费、制造业等是否出现超预期变化，关注前值修订、工资和结构。区分“增长改善带来盈利改善”与“增长过热推动利率预期上升”。强数据或弱数据都没有固定的股市方向。

B. 通胀与供给
查通胀数据、能源、运费、关税或供应中断是否出现新变化。区分需求变强和生产成本上升。搜索具体事件及其时间，不只搜索“通胀利空股市”。

C. 货币政策与收益率
查央行决定、讲话及政策路径预期是否变化；比较同窗口的短端和长端。名义收益率上涨只是待解释现象。预期名义短率与期限溢价是一种拆分，实际收益率与通胀补偿是另一种，不要重复相加。模型估计必须注明，不冒充实时观测。

D. 债券发行与资金供需
分别查国债供给和企业融资，确认公告、定价、结算时间及期限。区分计划融资、实际发行与已完成交易。寻求融资或融资新闻不能写成已经发行。融资新闻不能直接推出“资金从股市被抽走”；需要利差、定价、对冲或资金流的额外证据。

E. 企业与行业
查财报、业绩指引、监管、竞争及权重股事件。判断跌幅是否集中在特定行业或少数权重股。自选观察池不能当作全市场涨跌家数。

F. 地缘与政策事件
查战争、制裁、关税及监管新进展。明确传导渠道：供应、能源、成本、需求、盈利或风险补偿。事件和收益率变化可能处在同一条因果链上，不应机械当成互斥原因。

G. 仓位与杠杆放大
必要时查资金流、清算、融资压力及市场流动性。价格跌或波动率升本身不能证明去杠杆。加密资产需要检查自身的清算、资金流及重大事件，不能因为宏观共振就排除独立因素。

3. 使用本地与网络证据。
   优先检索已有的近期本地材料及原始引用，按缺口补查网络。优先官方发布、发行人文件和原始报道；评论文章提供假说，不能自动升级为事实。多篇转载同一来源只算一条证据。
   本地未命中不等于事件不存在；网页抓取失败（包括 403 等无法读取正文）或只有标题，也不等于已排除该方向，更不能据此写成“没有独立消息”。

4. 搜索变化，而不是只搜索故事。
   每个候选解释都问：本次新增了什么？相对什么预期？发生在价格变化之前还是之后？哪些资产表现支持它，哪些不支持？
   公布后数据、事后报道不能当作分析截止时点已经知道的消息。未来才发布的纪要不能解释此前跌幅。较早消息若被用作当天原因，应说明本次新增催化，否则仅作背景。

5. 允许中间结果。
   对每条有用线索保留：变化事实、时间、来源、可能传导机制、佐证、反证或缺口、下一步值得核查什么。
   状态用“有支持／存在反证／暂无证据／数据不足”。不编因果贡献百分比，不要求找出唯一原因，不为了填满结构凑材料。

6. 停止条件。
   沿用原有工具和时间预算。证据足够支撑谨慎回答时停止；遇到决定性缺口且现有工具无法补齐时说明限制；没有新线索时不要改写同一句查询反复搜索。
   由主 Ask 决定最终回答长度和形式，不强制把上述所有栏目展示给用户。
