# AI Center

AI Center 是一个从零开始的本地信息中枢。

第一版只验证一条最小链路：

```text
本地服务器 -> 手机直连 -> 信息展示 -> 快速发布 -> 两端实时同步
```

本仓库暂不迁移 `F:\AI` 或 `F:\Fintech\AI-Hub` 的既有功能。旧仓库仅作为后续能力接入时的参考来源。
