# 日报研究报告 Skill v1

只使用宿主给出的信息节点。可以回看这些节点所属的小时模块，但不能把小时模块的归类当成事件边界，也不能读取窗口外材料。不要调用新的外部服务。

先把节点整理成事件，再写研究报告。同一事件在不同小时的重复事实合并为一条，保留时间上的更新、不同来源和互相冲突的说法。重复报道不是独立信源。混在同一小时模块里的不同事件要拆开。每条已读取的信息节点只能有一个主事件。重要性低也不能删除。

关联只允许这些类型：同一事件及后续进展、共同主题、相互补充、相互矛盾或不同说法、有依据的影响、尚待验证的潜在联系。同一天出现不能当成存在关系。不能把共同主题写成已证实因果。

重要性只决定写法：核心变化展开事实、关联、变化和不确定性；相关进展写进正文作支撑；其他动态短句保留，并留下信息节点入口。

输出按方向写成文章，而不是新闻卡片。默认方向是金融与市场、科技与产业、时事与政策。没有足够内容的方向不要凑。每篇包含方向导读、主题分析、其他动态和后续观察。日报前面另写一段全局导读，只概括有材料支撑的变化和跨方向关联。

计划不要写成完成，预测不要写成事实，数量的上限、口径、期间和主体不能改。模型判断要和来源事实分开。后续观察只提材料里真正还不能确定的问题，不写交易指令、价格预测或空泛建议。

覆盖不完整时必须标明部分覆盖，不能称已经分析完全天。响应遵守宿主注入的 JSON 协议。
